# 战斗机制对照与移动目标修正

核对日期：2026-09-22。主体对照《Prototype》第一代；用户另选用二代式利爪空中飞扑。

## 依据与边界

- [发行版 PC 手册](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/10150/manuals/Manual_english.pdf?t=1655760765)：操作和目标锁定。
- [Prima 官方攻略](https://www.scribd.com/document/339963628/Prototype-Official-Prima-Guide)：第 11—14 页基础战斗，第 21—22 页锤拳/鞭拳，第 32—33 页挑空和空中衔接。公开镜像文字中的按键图标有缺失，不能据此猜测键位。
- 本机私有动画、动作归属和接触事件：用于动作与有效帧核对，不能证明已经恢复原版全部游戏逻辑。原版派生文件不进入公开资源目录。

原版提供目标锁定与绕目标移动；飞踢承担接近功能并能衔接抓取。浮空连段和下砸有特定衔接，鞭拳直线打击、远距抓取和横扫用途不同。慢重击可以被躲避；敌人种类和其当前攻击状态也影响能否打断。[官方攻略](https://www.scribd.com/document/339963628/Prototype-Official-Prima-Guide)

没有从这些资料确定原版的逐帧转向上限、追身速度或碰撞宽容数值；本次代码中相关常数均为 Minecraft 适配参数，不能称为原版数值。

## 发现的实际问题

1. Session 将 yaw/direction 固定在出招瞬间；目标后续横移不改变攻击轴。
2. 追身仅在地面前摇执行，每帧至多 0.14 格，且距离依据通用 reach，不能保证进入实际刀刃轨迹。
3. 原有轨迹补偿包含攻击者移动，但目标只使用当前包围盒。
4. 轻击、收尾、击飞和下砸缺少完整的落地后恢复生命周期。
5. 自定义怪物的攻击计时在 tick 内，单独暂停原版 AI 方法不足以阻止其倒地攻击。
6. 砸地招式仍受手臂局部碰撞约束，漏掉身后目标；普通锤拳缺少命中点周围的溅射。

## 本次实现

| 环节 | 行为与验收重点 |
| --- | --- |
| 目标选择 | 显式锁定优先；其次选择视线内前方目标；排除盟友、不可伤害玩家和被抓取对象 |
| 转向 | 前摇持续修正，接触阶段降低修正速度，收招停止；动画朝向与伤害轴同步 |
| 追身 | 有限且经过世界碰撞；冲刺动作已有位移，不重复叠加；不能穿墙或无限追赶 |
| 动态接触 | 采样玩家和目标在一个 tick 内的运动；大幅传送不产生沿途误伤 |
| 连段 | 保留合法输入缓冲和多接触窗口，轻击避免将目标直接打出下一招范围 |
| 目标反应 | 轻击、挑空、持续浮空、下砸、收尾分开；实际落地后倒地，再起身；暂停攻击决策 |
| 鞭臂 | 收拢/伸展共用刃模型；轨迹与显示共用中心线；远距抓取仍需伸出、接触、拉回 |
| 跳跃 | 地面奔跑蓄力保持惯性；墙面蓄力归一化到同一腿部缠绕强度 |
| 锤拳范围 | 普通命中产生小范围溅射，主目标不重复扣血；砸地按落点半径影响四周，均受墙体遮挡 |
| 轻重差异 | 体积和抗击退属性共同衰减冲量，大体型目标保留硬直而不强制浮空 |
| 特效 | 接触帧触发地面碎屑、冲击烟尘与声音；短拖影取自实际手臂/鞭尖运动，命中反馈只在伤害成功时触发 |

攻略第 21 页也明确提到普通锤拳有范围效果、Smackdown 具有落点溅射。这里的溅射半径、衰减和体积门槛是适配参数；Minecraft 生物并没有与原版车辆完全对应的质量系统。

## 不能把本次工作称作完整原版引擎移植

目前仍没有逐关节刚体布娃娃，非人形目标使用适配动画；所有原版敌人的攻击抗打断表、车辆战斗与劫持、断肢、完整环境物件战斗并未因此自动实现。本次验收针对已存在的五种武器、动态命中、受击生命周期、鞭臂和跑跳问题。

自动验证除静止目标外，还覆盖横向移动、后退、空中移动、小体型目标、脱离攻击范围、墙体阻挡。实际客户端另验收受击姿态、鞭拳收放、12 格抓取和地面/墙面蓄力跳跃。

## 2026-09-22：徒手、锤拳与携带同步

- 原型模式的无武器形态接入拳击、踢击、拳脚衔接和空中动作；只有双手空着时接管输入，工具和普通生存攻击仍走原有操作。徒手伤害与肌肉形态区分。
- 快速连点在前一招释放后保留缓冲；已经松开的下一次点击不会重新进入蓄力停顿。锤击、空挥和命中分开出声，地面裂纹、碎屑与短拖影在有效帧出现；每一招使用当时的位置，已经产生的裂纹留在落点后淡出。
- 连招换段保留有效目标，显示朝向、原生步进与伤害轴使用同一 yaw。普通近战贴近目标后削减向前步进；离开当前攻击距离后，旧运动轨迹不能再授权命中。
- 未锁定的空中攻击依据实际路径／落地点命中敌人。锁定后的空中动作可以向 12 格内可见目标接近；刀、锤下砸在较长起手期间也接近目标，再进入下降。追身范围不等于伤害半径：最终仍需接触，落地冲击也受遮挡限制。原版引擎的全部追踪参数并未移植，这些是适配数值。
- 携带阶段恢复冲刺、转向和移动投掷；抓取起手和正式吸收仍限制移动。冲刺碰撞排除被抓生物，投掷继承部分跑动速度。客户端让携带目标使用携带者的手部插值，防止高速奔跑时目标追逐旧网络位置；预测不越过障碍。此处适用于现有可抓生物，尚未新增建筑／环境物件搬运系统。
- 网络协议更新为 16；联机双方需使用同一版本。

验收使用玩家自己的第三人称镜头。外部摄影实体会使原版客户端停止发送玩家位移，不能用该镜头下的画面判断本地角色移动与服务器命中的一致性。

追加实机验证包含 12 组空中锁定／未锁定动态命中：目标持续横移并后退，直到真正受到攻击才停止测试移动。刀、锤和徒手下砸、空中拳击、飞踢、鞭拳均通过这一组检查。地面横移、后退、小体型目标与脱离范围由游戏内测试覆盖。结果说明这些测试路径可命中，不代表任何速度、遮挡和逃逸情况下都应必中。

## 空中右键与蓄力

| 形态 | 空中右键 | 本次处理 |
| --- | --- | --- |
| 徒手／肌肉 | 一代飞踢 | 点按完成起手后释放，按住蓄力；最大蓄力自动释放，同一动作按蓄力程度增强伤害 |
| 利爪 | 用户选择的二代式飞扑 | 独立双爪蓄势、飞行、撕击与收势；靠近当前目标后进入撕击，不再借用飞踢 |
| 刀臂 | 一代空中斩 | 保留独立刀斩动作、真实落地接触与蓄力 |
| 锤拳 | 一代肘砸 | 保留肘砸、落点范围伤害和地面反馈；不换成爪扑 |
| 鞭拳 | 一代空中鞭击 | 保留鞭臂曲线接触和独立蓄力释放动作 |

利爪飞扑由项目在 Blender 中新制作，来源为 `tools/author_claw_pounce.py`，可编辑工程留在本地 `tmp/claw-pounce-r32/claw-pounce.blend`。它是依据二代招式概念制作的适配动画，不是二代解码动作。仅这两份原创动作随包分发；一代私有派生动作仍在外部加载。

飞扑使用实体实际位移，单次飞行预算 18 tick；12 格是目标取得／追踪上限，不是隔空伤害半径。目标移动时更新接近方向，进入实际爪刃接触距离后才撕击；墙体、失效目标和远距离逃逸不能授权伤害。蓄力同动画释放招式的伤害最多增加 50%，属于本 Mod 的适配参数，不声称为原版公式。

没有显式锁定时，仍只从准星前方的合法目标中选取，不会随机换敌人；已取得的近处目标在空中可持续跟随。显式锁定优先，仍受视线和追踪距离限制。自动选择的刀斩目标需处于准星方向，水平看向远方时不会自动吸到脚下敌人。
