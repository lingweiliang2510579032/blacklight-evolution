# RC22：其他武器接招与全套动作还原现状

用户要求覆盖其他动作，不能将空手和利爪的局部更新当作全套原版还原。本轮继续核对刀锋、重锤、鞭拳的 FIG owners 和实际导出器，同时检查移动、抓取吸收和受击控制代码。

## 本轮已改：9 个其他武器接招点

在 RC21 的 7 项基础上，新增 9 项，共 16 项。数据仍由 `tools/extract_source_combo_timing.py` 从本地已解包文件提取，可追溯 block、owner 与事件偏移。

- 刀锋 A、C、C2 和重锤 B：直接读取明确且非负的 Input-only release hook。
- 刀锋 B、重锤 A/C、鞭拳 A/B：出招事件含尚未解明的负值标记，采用明确的 recovery Input hook，叠加已核对的 release 时长。没有把负值当成零。
- 鞭拳 A 的导出器保留 0.13 秒准备时长，因此不能一律取整为 0.133333 秒。该差异已纳入提取规则，并核对包内动作时钟。
- 均保留完整命中窗口、服务端伤害判定和现有连招分支；此次仅改变接招时间。蓄力加强变体、未核对的事件条件保持原有逻辑。
