# RC18：冰下研究站与主动觉醒

2026-09-26。本轮实现生存开局：寻找雪地制图师 → 地图定位研究站 → 探索并取得封存样本 → 主动觉醒 → 接入已有抓取吸收和成长系统。

## 玩家流程

1. 寻找雪地村庄的制图师，用纸交易升到学徒级。其海洋探险地图交易槽替换为研究站地图，基础价格为 12 绿宝石 + 1 指南针，价格仍受原版供需、声望影响。
2. 地图红叉指向冰下研究站。地表是青色条带的入口小屋与红色信号标记，楼梯通向地下实验室、隔离区、冷藏区。
3. 实验室补给箱提供铁剑、面包和火把。站内有两只使用现有 RC16 僵尸感染形态的持久感染体，没有新增怪物模型。
4. 冷藏箱固定含 3 个病毒样本。未感染玩家按住使用键 40 tick（正常情况下 2 秒）完成觉醒，提前松开不会消耗样本。感染后保留原有 B 切换黑光模式、E 抓取、右键吸收、U 升级操作。
5. 已感染玩家潜行并使用样本可投掷感染生物；普通使用提示操作，不消耗样本。接触传播、样本溅射和发射器均不会强制感染玩家。调试命令仍可感染。

移除普通材料合成样本的配方；旧存档已有样本仍可使用。此次未改变既有能力、进化点或死亡保留规则。

## 引导与存档

首次进入且尚未完成黑光根进度时提供一次线索消息，之后以根进度记录完成状态，不在每次登录重复提示。进度链为根进度 → 研究站 → 样本 → 觉醒 → 原有吸收与成长。

研究站通过原版 jigsaw structure / structure_set 生成，仅分布于新生成的积雪平原和冰刺之地。模板 23 × 21 × 23，包含地下部分和地表信号杆；每 24 × 24 区块区域尝试一个候选点，受生物群系过滤，不代表每个区域必有研究站。模板由 `tools/build_research_station.py` 原创生成，可重复导出，使用 Minecraft 原版方块。

旧区域不回填建筑，旧村民已经保存的交易不重置。应寻找尚未解锁学徒交易的雪地制图师；其他村民类型仍保留原版地图。如果原版地图搜索范围内没有可定位的研究站，回退到原地图交易。实验性村民交易重平衡或其他 Mod 替换交易表的情况尚未验证。

样本箱采用原版容器战利品保存规则，不无限刷新。多人可以分享三个样本，也可探索更多研究站。

## 构建与验证边界

本地版本保留 RC17 的 199 个动作 JSON 和三份配套数据；所有动作资料按 RC17 清单核对 SHA-256 后复用。源码 Git 提交不包含私人解码动作和本地安装包。

使用 Java 21，执行 `gradlew.bat clean assemble -PbundleMotionDirectory=<本地完整动作目录>`。必须清理旧输出，避免 Gradle 资源复制遗留已删除的合成配方。此机器复用既有 Gradle 离线依赖缓存；Windows JDK 的 socket 临时目录需指定为非缩写路径。

已完成编译打包和包内资源核对。依照当前项目约定，本轮未运行自动测试、GameTest 或启动用户游戏。自然地形下的入口高度、地图定位、隔离区交战、取消使用、存档重进与多人行为仍需实玩验收。既有 Epic Fight 过时 API 编译警告仍存在。

本轮交付范围是生存开局。城市、黑色守望基地/巡逻、超级士兵、独立新怪物模型、蜂巢活体表现和完整中后期成长仍待后续实现。
