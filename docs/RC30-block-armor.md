# RC30：原版参考的 Minecraft 方块装甲

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.30。
网络协议 27，客户端与服务端一起更新。

## 已接入

- 使用用户确认的第四版造型：封闭面甲、颈部甲刺、宽胸窄腰、层叠腹甲、前臂刃刺和腿甲。参考本地原版装甲外观，所有几何重新用方块制作。
- 119 个建模方块，跨躯干、肘、膝的基础壳拆分后形成 124 个关节部件。与 Epic Fight 身体骨架一起运动；完全覆盖后隐藏相应皮肤和外层衣物。
- 自制低对比像素甲壳贴图。模型和贴图可随源码提供，没有复制原版模型或贴图。
- 从 `alex_act_armor_transformation_armor` 解包片段采样甲片的累计缩放，按部位映射 30 条来源曲线，以 30 FPS、121 帧范围（约 4.03 秒）驱动分块生长。曲线单独保存在私有 `armor-growth.data`。
- 重导身体变形动作，剔除原版用于身体缩隐的 SCL 通道，避免该缩放沿骨架传递、挪动肘膝等关节。原始旋转和平移继续由已有重定向流程处理。
- 甲片生长时附着短暗红组织细丝；切换武器时保留肩甲，并让出武器覆盖的上臂、前臂。护盾与装甲各自完成出入过渡。
- 收起时从当前形状收缩，短时间重新开启从当前形状继续生长，避免切换瞬间跳到完全展开。

## 还原边界

原版甲片缩放时序有解包依据；将曲线映射到方块、归一化生长比例、绕方块中心长出、组织细丝及 0.45 秒收起均为 Minecraft 适配。本轮没有移植原版甲片平移、旋转、剪切、SCLP/SCLT 或游戏着色器，也没有把倒放展开称为原版收起动作。

静态模型外观按已确认第四版实现。此处接入的是装甲；护盾沿用 RC29 游戏模型，未把尚未确认的护盾草模一起替换。

保留 RC29 装甲可减免伤害倍率 0.525、禁用滑翔与低障碍自动翻越等规则。移速 -25%、击退抗性 +0.6 仍是此前 Minecraft 适配，不宣称为原作解包数值。

## 资源与构建

- 模型源：`art/armor-block-v4/armor.bbmodel`、`layout.json`。
- 原创模型生成：`tools/author_armor_block_v4.py`。
- 关节绑定、像素贴图与私有生长曲线导出：`tools/export_block_armor.py`。
- 身体片段导出：`tools/export_utility_motions.py`。
- 私有资料共 213 份：RC29 的 211 份保持不变，替换一份身体变形动作，新增一份甲片生长数据。原版派生数据仅随本地私人包提供，不提交公共仓库。

执行编译、打包、资源结构和模型法线检查；另用实际导出模型与动作做离线骨骼预览。没有执行自动测试、GameTest、启动游戏或自动游戏验收。实际第三人称动作衔接、材质、武器组合和联机表现仍需试玩。

## 安装

退出游戏、备份存档，移走旧版 Blacklight JAR，再放入 ZIP 的 `mods/` 内 JAR。不要同时放入多个 Blacklight 版本。前置保持 Java 21、NeoForge 21.1.244、Epic Fight 21.17.3.1、GeckoLib 4.9.2。

安装文件统一命名为 `Blacklight-Ascension-MC1.21.1-NeoForge-0.2.0-rc.30`，同时包含 Minecraft 与 Mod 版本。完整本地包已内置私有动作，无需外部动作目录。G 开关上次防御能力；也可用 Z 轮盘的防御分页选装甲。
