# 抓取与吸收规则

这是结合 Prototype 的弱敌直接抓取、强敌先削弱思路和 Minecraft 生命属性的自定义规则，不是原作的数值复刻。

| 最大生命值（生命点，2 点 = 1 颗心） | 抓取 / 开始吸收条件 |
| --- | --- |
| 小于 50 | 存活即可，不要求先削弱 |
| 大于或等于 50，包括 50～150 及以上 | 当前生命值小于或等于最大生命值的 15% |

例如：最大生命 50 → 7.5；100 → 15；150 → 22.5；500 → 75。
以实体实际的最大生命属性为准，包括属性强化；不以当前生命反推体型或类别。
被动动物不再豁免血量门槛。旧 consumable_without_weakening 标签仅保留用于进化点奖励分组。

生物还必须在 blacklight:consumable 数据标签中。补充劫掠兽、监守者、守卫者、远古守卫者、炽足兽；RC2 已加入铁傀儡、雪傀儡、凋灵、末影龙，大型目标使用攀附而非手持，Boss 保留原生死亡流程。第三方生物可通过数据包扩展该标签，仍遵循同一血量规则。

保留驯服宠物/坐骑、被拴住、骑乘/载客、无敌、已被抓取等限制。
抓取时以及按右键开始吸收时均在服务端检查血量。已抓住后发生外部治疗、恢复超过门槛时不能直接开始吸收，仍可投掷。
抓取仍需真实距离和视线可达：普通 3 格，鞭拳 12 格。大型目标先将玩家移向攀附位置，保持目标原大小；攀附完成右键吸收，左键或 E 松开。
