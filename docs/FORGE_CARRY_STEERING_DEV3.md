# Forge 1.20.1 dev.3：同步抓取转向

本版将 NeoForge PR #5（`47e0e103`，dev.8）中的抓取持有修复适配到 Forge 1.20.1 / Java 17。Forge 移植 PR #6 接入主仓库的 `forge-1.20.1`；`main` 继续维护 NeoForge 1.21.1。

## 行为

- 第三人称抓住生物后，W/A/S/D 仍按镜头方向移动，持有者可朝移动方向转身。转身时同时换算输入，避免反向跑或把移动向量重复旋转。
- 持有者、握持位置与受抓生物使用一致的帧间朝向插值，减少转弯时身体拖后或漂移。
- 只开放 HOLD 持有阶段；捕获、吞噬、投掷等动作继续遵守各自阶段约束。松开方向键不产生额外位移。
- 保留 Forge capability 访问与 Java 17 的夹取实现；不改伤害、F8 参数、动作资源或平台依赖。

## 验证

针对 `CarrySteeringTest` 的三个回归覆盖 270 组镜头/人物朝向与方向键组合、后退及侧向转身、无输入保持姿态。构建还须检查重混淆成品、内嵌 MixinExtras、非空 refmap 和 224 个动作/HUD/镜头文件。

dev.2 原有全量测试记录为 202/206 通过，四个旧预设/断言差异见 [移植状态](FORGE_1_20_1_STATUS.md)。本次针对性回归不代表这些旧失败已解决。Forge 客户端抓取试玩、专用服务器和多人验收仍需验证。

## 版本协作

在 `forge-1.20.1` 创建功能分支，PR 的 base 也选 `forge-1.20.1`。跨版本同步以具体修复为单位，保留加载器 API 和 Java 版本差异；不要将 Forge 全平台移植合入 NeoForge 主线。构建文件名同时包含 Minecraft 版本、加载器及模组版本。
