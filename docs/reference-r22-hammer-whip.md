## 已核实的招式分类（文字证据，不是姿势观察）

官方攻略的公开文字区分普通锤拳最多四击的连招、Smackdown、带 Downpunch Finisher 的变体和 Hammertoss。Hammertoss 是冲刺中的自身投射；不能用原地重拳或普通冲拳替代。攻略另描述跳起后执行 Elbow Slam。这些描述不提供逐帧的支撑脚、手臂角度或起落时间。

来源：[Prima 官方攻略](https://www.scribd.com/document/104597219/Prototype-Prima-Official-eGuide-pdf)。本段只作简要释义，未转载攻略正文或图片。

下列二手资料用于交叉区分两代，不能替代原版录像：

- [Hammerfists 资料页](https://prototype.fandom.com/wiki/Hammerfists)分别列出 P1 的 Smackdown、Elbow Slam、Hammertoss，并另写 P2 的 Groundspike、Divebomb 等。不要把 Heller 的锤拳地刺搬成 Mercer 的锤拳。
- [Whipfist 资料页](https://prototype.fandom.com/wiki/Whipfist)列出 Street Sweeper 与 Longshot Grab；前者是周身范围的扫击，后者是远距离抓取。直线攻击、扫击与抓取不能共用同一个伸直手臂的姿势。该页明确将攻击后鞭体扬起再砸地的收尾描述放在 P2 部分，不应未经验证加给 P1。

## 每招待核查清单

| P1 招式 | 已知用途 | 仍缺的连续视觉证据 | 当前可做的结论 |
| --- | --- | --- | --- |
| Hammerfist 普通四击 | 地面连招，可提前结束 | 每击用哪只手，迈步次序，肩胯与拳的相位，第四击的终结姿势 | WOM Torment 不能仅凭名字充当这套连招 |
| Smackdown | 缓慢、强力的砸击 | 蓄势如何长大/抬拳，重心先升还是先沉，击地顺序，失衡与恢复 | 不生成臆测的全身关键帧并称之还原 |
| Elbow Slam | 空中转入向下攻击 | 空中预备的屈肘方向、双腿收拢、下降姿态、接地与起身 | 不能误用 P2 无预备的快速落地动作 |
| Hammertoss | 冲刺中的自我投射 | 蹬地脚、双臂先后、水平飞行轮廓、落点与恢复 | 需要真正的实体移动和碰撞同步，原地摆拳不符合其机制 |
| Whipfist 定向攻击 | 单个方向的长距离打击 | 抽臂、转肩、出鞭弧线、最大伸展时躯干朝向、收回轨迹 | 身体与鞭体必须共享同一接触时刻；方向尚不可凭空指定 |
| Street Sweeper | 周身扫击 | 第一脚支撑、步法交替、身体转数、鞭尖先后经过角度、收鞭 | 360°伤害范围不等于人物根骨匀速旋转一整圈 |
| Longshot Grab | 远距离抓取 | 发射前动作、鞭体伸展、击中缠绕、拉回时髋/肩反向、最终持握 | 攻击和抓取要分开；抓回之后还需衔接吸收姿势 |

## 录入动作前的证据要求

至少为同一招保留一段能看清身体和脚的原版连续画面，记下起手、最大蓄势、接触、跟进、恢复五个时间点。左右手必须按角色自身坐标判断；正面和背面镜头不可混淆。若镜头旋转，人物世界转向与摄像机转向应分开记录。只有确定这些内容后，才能写骨盆、躯干、肩、手、腿和实体位移曲线。

当前锤拳、鞭拳的结论是：**已定位待看的 P1 来源，尚未取得足以重做动作的连续姿势证据。** 现有 WOM 适配只能继续标记为临时动作，不能改名为原版还原。
