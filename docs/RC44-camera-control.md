# RC44 镜头控制与跟随修复

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.44。本地试玩候选版。

本次针对镜头深度审计的八项问题修复代码，继续使用现有解包动作、镜头曲线及 HUD 资料。

- 自定义镜头接管时，统一鼠标、移动意图、攻击方向和 Epic Fight 的方向读取；不再取决于另一个 `ON_AIMING` 开关。鼠标输入只消费一次，同一帧尚未渲染的输入也能用于移动和攻击。
- 主动转动鼠标后，目标取景、动作重瞄和跑动构图让出朝向控制。锁定目标本身保留，地形和锁定状态切换不撤销手动观察。
- 普通鼠标观察不再同时触发 Epic Fight 的快速换目标。自动换目标调用不再伪装为明确的切换操作。
- 地面、空中、墙面和锁定使用统一的 −80°～80°观察范围；手动墙面观察不再受墙面法线硬改角度，也不再随俯仰改变横向灵敏度。相机位置仍进行碰撞保护。
- 跟随滤波按移动速度缩短窗口，锚点滞后距离限制为正常体型 0.45 格（随体型缩放）。接触遮挡时投影到安全位置，恢复时保留平滑，避免高 F8 速度把跟随锚点拖出数格。
- 变形演出中移动鼠标会从当前可见朝向接管，并取消当前这一次镜头演出。位置和 FOV 通过约 0.18 秒的交接恢复，身体变形动画继续按原有规则运行；新的变形仍可播放镜头。
- 使用物品/瞄准与普通观察之间加入位置、角度和 FOV 交接；临时交出镜头不会丢失原有手动状态。重生、换世界和切换视角仍清理相应状态。
- 自定义奔跑 FOV 增幅遵守 Minecraft 的 FOV 效果强度设置。

原来的 F8 移动速度、跳跃、伤害与生命设置不变；原作资料文件未改写。本包包含 RC43 的头像方向修正。

验证范围：编译、安装包内容与 Mixin 目标签名核对。按现有项目约定，不自动运行测试、GameTest 或游戏内验收；实际手感与不同地形下的表现待用户试玩。编译成功不能替代实机验收。

推荐试玩顺序：自由观察时 W/S/A/D 转向；锁定多只怪物后移动鼠标；空中仰视落地和绕墙角；高速度跑坡地；变形途中转镜头；吃东西或拉弓再恢复移动。无需重新调整 F8 才能启用本次修复。

安装包：`Blacklight-Ascension-MC1.21.1-NeoForge-0.2.0-rc.44.zip`。退出游戏后替换旧版 Blacklight JAR，保留当前依赖。当前已运行的客户端不会因编译而自动更新。
