# R13 持有接触位置

修复试玩截图中“提示已抓住，但鸡仍悬在双爪前方”的错误。

原位置固定在玩家身前 1.05 格、侧向 0.28 格，且小型生物最多只抬高 0.65 格，和实际左掌位置不符。现在以持有动画的左掌位置为基准，计入玩家模型缩放，按生物宽度将身体近侧贴向掌心、按高度决定抬升量。持有渲染朝向与视角方向一致，避免转动视角后手和目标朝向分离。抬头和低头会改变持有点的高度与前伸距离；服务端仍通过实体碰撞移动目标。客户端以掌心作为求解末端（不再反复补偿手腕偏移），按目标实际插值位置求解肩膀和肘部的逆向运动学，避免网络插值、目标体型和碰撞造成掌心脱离。

新增资源回归检查：对实际利爪网格的掌心做正向骨骼计算，验证整个持有循环与服务端挂点相符。新增服务端回归检查：成鸡、幼鸡抬升至掌心高度，抬头、俯视、平视与四次转向后保持抓取。

独立客户端录制 `-PcaptureGrabContactPreview=<输出目录>` 覆盖成鸡俯视、成鸡侧面、幼鸡、猪、村民与持鸡转身。各场景检查俯视、仰视和平视。镜头不再强行设置玩家身体朝向；记录实际渲染掌心与生物身体包围盒的距离，零渲染采样也判失败。该测量用来发现明显脱离，不能替代模型表面的目视检查。

R13 没有新增独立手指骨骼或逐指握紧动画；本轮解决持有位置与朝向错误。
