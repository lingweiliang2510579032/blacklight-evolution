# 玩法补全工作单

用户已确认整体范围：Z 技能圆盘；全部武器攻击动作和技能；多种怪物与蜂巢；成长和生存。后续迭代保留全部范围，不能把模型或状态字段记为成品玩法。

制作顺序与交付门槛：

- [ ] Z 按住选择、松开确认的能力圆盘；展示解锁情况与形态技能，服务端验证切换。
- [ ] 武器独立战斗：利爪保留既有连击/地刺；刀臂连斩/重斩，锤拳拳击/震地，鞭拳抽击/横扫，空中和移动攻击；独立动作和判定。
- [ ] 补全剩余能力：肌肉强化、护盾、铠甲和视觉能力，明确与武器的共存规则及成长条件。
- [ ] 独立感染体：近战、快速扑击、远程攻击和精英各有行为、模型与预警。
- [ ] 蜂巢：世界遭遇、核心与守卫、受控增援、摧毁结算、多人/卸载持久化。
- [ ] 生存入口与成长：获取病毒、阶段指引、吸收和蜂巢奖励、升级用途、解锁目标与旧档兼容。
- [ ] 整合服务器、客户端实拍、发布包验收；逐项报告已完成和仍待完成部分。

既有约束：不重置旧存档；原版模式恢复生存操作；已学攻击技能不消耗生物质；服务器拥有伤害、奖励和解锁判定；怪物与蜂巢必须有数量和刷新预算。
