# RC20：形态切换、转向与动作取消

用户反馈：轮盘选择无能力后，空手右键偶尔仍放地刺；主角总朝前，动作缺少打断与衔接。

## 本地原版数据核对

读取已有私有解包结果 `prototype-research/local-private/fig-r25-basic/prototype_bare-owners.json`、`prototype-owners.json`，以及 `fig-r22/prototype_claws-owners.json`。未重新解包，也未将原版数据纳入 Git。

- 裸手 special_combo 的膝击使用 `alex_special_knee_left`。windup、hold、release、transition_to_idle 是独立 owner；release 内输入事件的 time_hook 为约 0.333333 秒，transition_to_idle 从 0 秒监听 Input。说明动画尾部与输入响应不能简单等同于整段播放结束。
- 同一膝击把源帧 9–16 压到约 0.066667 秒，随后分别播放 16–24、24–30；收招另有 0.1/0.266667 秒 blend-in/out。直接匀速播放原片段无法复现这种节奏。
- 原版普通 locomotion 的 180 度转身片段分成 0–0.2、0.2–0.4 秒两段，并从 0.2 秒出现 orient 轨道；另有 locoSteer、locoStrafe。朝向控制与骨骼动画需要配合。
- 利爪的特定 release/retract 和抓取处存在 uninterruptible 轨道。不能据此把所有动作设为随时取消，也不能把整套动作统一锁死。部分轨道回调、负时间哨兵、motionState 消息的引擎语义仍未解明，不能宣称完整还原了原版状态机。

## 本版修改

1. 修复轮盘选择无能力在攻击期间被静默拒绝的路径：收起武器会清理当前武器动作、连招及旧按键状态；其他能力忙碌时切换失败会明确提示。客户端形态改变后要求松开旧鼠标按键再重新按下，地刺生成处再次校验利爪形态。裸手右键仍为膝击。此路径能够解释反馈，但尚未在游戏中复现并确认它是唯一原因。
2. 自由地面移动的身体朝向平滑跟随行进方向，镜头独立；锁定目标、攻击、抓取、墙跑等保留各自朝向控制。方向动画与身体使用同一个朝向。攻击视觉更新不再强行改客户端镜头角度，无目标普通攻击准备阶段可有限转向，命中方向与动作朝向一起更新。
3. 普通地面攻击保留完整命中区间，结束后留 2 tick 跟进即可用移动退出收招；已缓存连招优先，空中攻击/落地攻击仍由原有动作控制。地面武器蓄力可按跳跃取消，使用跑酷系统采集的物理跳跃边沿，避免 Epic Fight 清除跳跃标记后丢输入。
4. 刹车阶段重新开始移动会立即离开刹车；跳跃或蓄力不再保留过期的地面过渡计时。

以上转速、2 tick 收招余量、跳跃取消属于 Minecraft 适配规则，不声称是原版精确参数。原始动作包保持不变。本轮未加入受击硬直对玩家攻击的完整打断规则。
