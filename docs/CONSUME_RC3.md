# RC3 吸收对位与目标反应修复

针对 RC2 试玩反馈：吸收能结束，但主角与目标错位、穿模，目标受击状态不明确。

- 六种普通体型吸收使用逐帧手部与头部/胸口接触数据。移除各自归零后再加固定距离的摆放方式；按 Minecraft 体型限制躯干重叠和脚部入地。
- 同步吸收开始时的朝向。客户端根据同一进度修正目标渲染位置，减轻网络插值造成的双方脱节；有阻挡时不跨墙修正。
- 人形目标使用成对接收动作。普通模型按骨架初始姿势转换整条躯干、肩部和肢体变换，替代直接叠加局部欧拉角。动物保留物种姿势适配；受制时停用走路、攻击等基础姿势。
- 命中时双方共用两 tick 的动作停顿，同时触发目标受击变红、接触音和粒子。不会额外扣血或改变吸收资格。
- 原动作中的肢体运动不再叠加第二次横向偏移，末段才收缩吸收部位。临时模型变化在绘制后恢复。

本地动作配置的 consume-placement.data 更新为 schema 2，须与 RC3 一起使用；网络协议为 22。原版衍生动作和接触数据只放本地私有配置，不加入公开资源。

只编译打包，未运行自动测试、GameTest 或游戏内验收。接触约束是 Minecraft 骨架适配，不能据此宣称完全复刻原版或所有物种均无穿模。大体型攀附沿用 RC2；第三方骨架仍可能需要专门适配。
