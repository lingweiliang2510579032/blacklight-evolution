# RC13 — 滑翔、感染宿主与本地猎手模型

## 滑翔
- 滑翔进入时提供起速，保留跑跳 / 空中冲刺的水平动量。
- 独立保存滑翔速度，避免原版空气阻力抵消每 tick 的微小加速；高速平滑回落。
- 后拉减速；有转向速度限制；碰墙、落地、水中或动作接管时结束。
- 同步短期滑翔状态，黑红连续尾迹沿世界坐标保留转弯轨迹，开启时有风声和粒子。
- 机制参考《Prototype Official Prima Guide》的 charged jump → air dash → glide 路线。数值为 Minecraft 适配，不是原版精确物理参数。

## 感染
- 新增独立 infected_host 实体。普通 Mob 感染过程结束后替换为保留物种外形和外观变种的感染宿主；已感染旧存档生物也会转换。
- 使用原物种关节模型，表面黑光组织、红色纹理变化及沿模型表面生长的尖刺；尺寸和能力增强。
- 按地面、飞行、水生分类运动；名称、装备和乘客迁移；生成失败保留原实体。
- 被抓取 / 吸收 / 受击控制时推迟转换，避免中途换实体造成旧的错位问题。
- 末影龙、凋灵保留原 Boss 逻辑，暂不接通通用感染替换；不影响既有抓取吸收规则。第三方特殊生物的专用渲染器与 AI 尚待用户验收。

## 猎手
- 本地原版 Brawler.p3d：3789 顶点，3442 三角面，原始漫反射贴图和四权重蒙皮。
- 网格绑定到当前 13 个受击 / 吸收关节；手指并入对应前臂，未声称恢复全部原始骨骼。
- 加入原版待机、行走、奔跑和单击旋转轨迹；Minecraft AI 驱动位置，保留已有受击和吸收。
- 原版派生文件仅在本地私有 profile 中；公开 Jar 无原版网格、贴图或动作素材，缺少私有 profile 时使用原创模型回退。
