### 支撑脚的边界

能确认地面技能和恢复期不是直膝站立：膝屈、髋低、躯干前倾，并有明显站立高度变化。但录像分辨率只有 480×360，脚底常被烟尘、角色或场景遮挡，不能可靠给出每阶段“左脚固定、右脚蹬地”的标记。普通跑动帧的交替脚步也不能移作攻击发力证据。

## 第二段 HD 尾部：可用于普通爪击样板的轮廓

这段有清楚的普通近战挥爪外形变化，但血效、附近感染者和片段结尾阻止了完整连段分解。以下连续观察**不等于已经确认它是固定第几段轻攻击，也不保证是一招而不是短连击**。

| 相对时间（约） | 可见姿势与运动 | 对还原样板的意义 |
| --- | --- | --- |
| 9.00–10.00 | 地刺收回期间，角色仍低蹲，附近感染者走近 | 必须将地刺后状态与后续普通攻击分开；不能把前面一秒低蹲全部算进轻攻击起手 |
| 10.10 | 角色立起，一侧爪臂抬到头顶上方，另一臂处于躯干下侧；胸、肩与髋不在同一方向；爪尖轮廓明显越过头部高度 | 有高低不对称的准备轮廓，并非双臂平伸；关节关系需要连同上体一起做 |
| 10.20 | 高举爪臂从近竖直转为头部上方的斜向，角色上体朝近旁目标转入 | 武器方向变化伴随躯干转向；不只是肩关节原地摆动 |

| 10.80–10.90 | 可见髋部降低、双膝明显弯曲，躯干前倾并转向；爪臂在低位横向经过身体前侧，身体位置随动作推进 | 可以确认有转体、下沉和横向跟进。不是在完全直立状态下左右摆手 |

左右手说明：本段摄像机位于角色附近斜后方，角色自身发生转向，部分肩关节被遮住。本文保留“高举侧/低置侧”和画面轮廓，不把未经确认的屏幕左右硬映射到角色左右。完整左右臂和脚的确认仍需另一角度或更干净的原版录像。

## 可用于当前样板的实施约束（设计判断，不是额外原版事实）

- 先复现已观察到的五个轮廓：低位起身 → 单侧过头准备 → 斜向压入 → 转体下沉横向跟进 → 低位恢复。保持头、胸、髋、腿随同变化。
- 高举阶段和低位跟进阶段的身体高度差必须可见；不能把差异全部放到双臂。
- 地刺单独处理，普通爪击不要继承录像中地刺的长时间插地停顿。
- 接触时刻可先对齐“爪臂进入目标＋身体压入”的阶段；数值帧数属于 Minecraft 节奏设计，不能称为从录像精确反算。
- 可为样板选一个不会滑步的支撑脚方案，但在获得新证据前应标注为适配选择，不能称原版左右脚复刻。
- 本次不支持完整轻攻击段数、逐招命名、冲刺爪击轨迹、精确步法和全部后摇的还原承诺。

结论：第一段适合地刺和移动研究；第二段尾部提供普通爪击的全身高低变化和转体跟进轮廓。两段都不足以证明完整原版爪击连段或 Dashing Slice 已被逐帧核实。
