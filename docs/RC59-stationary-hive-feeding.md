# RC59：固定蜂巢捕食与 Boss 供养

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.59。

## 玩法

巨型组织蜂巢的四个营养节点成为固定捕食口。每座巢一次选用一个完整、可见的捕食口，搜索口周围 24 格内、巢室中心 40 格内的可用生物。蜂巢伸出触手、缠绕猎物，先抬起再拖回固定吸收口，最后收缩吸收；成功完成后才把生物质和一次进食记录记入原有宿主成长数据。

主体动作约 6 秒：伸出 1 秒，抬起 0.9 秒，拖回 2.9 秒，吸收 1.2 秒。正常餐后间隔仍为 25 秒；已有局部加速指令仅缩短等待和成长时间，不省略吸收动画。预存养分已够时仍会等待成熟或成长消耗，不无限吃光库存。

Boss 在成熟前不追击猎物或玩家，留在巢室，使用低头、胸腔呼吸和受养脉动姿态。旧存档中已经离开中心的宿主会尝试返回；不传送、不清除地形。成熟后恢复已有战斗 AI。本轮没有新增成熟巨构的专属战斗连招。

捕食口使用方块式组织颚、骨齿和根部模型。开口、缠绕、猎物收缩及地面血管中的养分回流均使用同一进食时钟。固定锚点来自保存的巢室坐标，不跟随 Boss 转身、移动或体型缩放。巢穴仍保留可破坏的方块外壳，并非整体替换成不可破坏的大模型。

## 干预和保护

- 捕食触手有三个可受击的组织结；命中并造成有效伤害后中断此次捕食，释放猎物。
- 拆掉正在使用的营养节点立即中断，即使其他节点仍有两个以上。完整节点总数少于两个时，沿用原有停止供养规则。
- 核心死亡或卸载、宿主失效、猎物被玩家接管、拖拽碰撞或视线受阻时释放猎物，不获得养分。
- 沿用宠物、命名生物、骑乘或拴绳生物、首领等排除条件。触手不能被感染、抓取吸收或计入感染人口，也不提供击杀收益。
- 吸收保留正常伤害和死亡事件；伤害或死亡被取消时不增加生物质。释放时恢复猎物捕食前的重力标记；读档会清理未完成的旧捕食声明。
- 触手受击部位不写入存档，结束时统一清理。不强制加载游戏区块。

## 安装与兼容

保留 RC57 的 224 份角色动作、镜头和 HUD 资料，逐文件 SHA-256 核对一致。旧蜂巢的归属、营养节点、已吞噬数量、生物质和成长进度继续使用，无需重新生成蜂巢。

新增触手实体和孕育同步字段，网络协议升至 37；多人两端必须更新到同一版本。文件名继续包含 Minecraft 版本和 Mod 版本。既有 RC57 发布包不覆盖。

测试入口：`gradlew.bat runGameTestServer -PhiveFeedingTest -PbundleMotionDirectory=<原动作目录>`，在独立 `run-hive-feeding-gametest` 世界执行。测试源和测试结构不会进入发行 JAR。游戏内模型观感、第三人称演出和复杂自然地形仍需人工试玩。

## 本轮验证

Java 编译通过；独立 NeoForge GameTest 服务端的 5 项场景测试全部通过：固定捕食一次结算、受击切断触手、破坏正在使用的节点、墙体遮挡拒绝捕食、核心移除恢复原重力标记。原动作目录的 224 份资料与 RC57 公开完整包逐文件校验一致。尚未完成客户端视觉试玩。
