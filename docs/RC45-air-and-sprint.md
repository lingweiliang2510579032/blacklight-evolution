# RC45：空中攻击、冲刺与水面起跑

## 空中左键平移

空中普通连击以前也满足通用远距离追击条件，会在自动选中远处生物后冻结预备姿势、持续移动到目标附近。这会把普通左键变成远距离飞行，并呈现“人平移、动作不动”。RC45 将普通空中连击和空中拍击移出远距离追击，普通连击只在自身接触范围附近选取目标。

通用空中攻击的减速下落/近距离追击现在只在有效攻击阶段运行，空挥不再持续抑制重力。有移动输入时，普通空中连击在保留全部命中窗口后可退出收招；已缓存的连击优先。飞踢、炮弹、利爪扑击等专用移动招式保留自己的路径。

攻击结束后按实际上升/下降恢复空中动作，不再统一强塞站立。客户端即使始终处于 FALL，也会在武器动作结束时重新交接。旧动作的播放速度不会读取另一招的暂停标志。

## 鞭拳空中重击

移除远距离飞到目标与近距离拉动施法者两条路径。改为蓄力和有效鞭击阶段在原处悬停，收招恢复下落。客户端和服务端使用同一武器时间窗，未写入永久无重力状态；落水、骑乘、飞行等冲突状态停止这次动作。

本地原版证据来自 startup_fig.p3d 的 prototype_whipfist：air/actions/attacks 中的攻击链与抓取链是不同分支；攻击 release 的动画字段为 alex_whip_longshot、起始帧 18。检查过的攻击分支没有目标飞行追击轨道，不能据此套用通用 flyingAttack。共享运动分支包含 fall，故本轮也保留收招下落。

边界：当前私人资源中的 whip_air 时间线仍是此前以地面 longshot 导出的替代时间线；本轮未重新导出223份素材。悬停到有效鞭击结束是 Minecraft 手感适配，不能称为原版空中攻击全部时序和物理参数的逐项复刻。

## 冲刺与水面衔接

原加速直接加在已经受地面摩擦衰减的速度上，上限调高也不代表能达到上限。现在连续冲刺保留自身加速进度，客户端与服务端共用计算，仍受 F8 上限、成长和装甲倍率约束。转向、碰撞、停止/中断、零加速会约束或释放这份动量，不改变跳跃力度。

水面支持不再要求先达到最低水平速度，允许从接近静止重新起跑。落水后继续发送前进/奔跑输入，同时禁止水底触发陆地蓄力跳跃。感染者在原型模式中按住前进与奔跑键，会向水面游升并接续水面奔跑；松开前进或按潜行可退出。水下速度与上浮速度单独限制，固体顶部仍然阻挡，不传送到水面。
