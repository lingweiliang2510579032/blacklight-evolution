# RC41：纯血条与属性面板

版本：Blacklight Ascension / Minecraft 1.21.1 / NeoForge / 0.2.0-rc.41。

感染后左上角血条移除生命文字、当前值、上限及吸收数字，仅显示血量比例与受伤后的缓退效果。血条保持固定长度，生命成长不会增加心形图标行数；额外吸收生命用下方细金条表示。护盾等状态提示随血条收紧后上移。

按 **U** 默认进入新增的“属性”页，可用滚轮浏览。原有移动、利爪、武器形态、生物成长及辅助能力升级仍在左侧分类中。

属性页读取当前玩家状态，显示：

- 当前生命 / 最大生命、额外吸收生命。
- 当前武器形态；已解锁时显示护盾耐久 / 容量。
- 当前形态普通首击的未蓄力基础伤害参考值，使用新生命单位，不计目标护甲、抗性及其他条件加成。
- 攻击速度属性、移动速度属性、当前水平速度、当前配置及成长等级对应的冲刺速度上限。

原生技能使用各自命中与连段时钟，攻击速度属性不代表所有技能每秒的实际攻击次数。速度上限也不等于地形、碰撞和加速过程中的即时速度。

沿用 RC40 的感染后基础 100 生命与敌我同步换算，不再改动战斗数值。网络协议仍为 35。动作与镜头资源仍为 222 份，与 RC40 相同。
