# RC50 吸收身份与本体切换

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.50。

> 以下记录 RC50 的历史行为。伪装暴露和换装脱离追踪规则已在 [RC54](RC54-disguise-and-hive-commands.md) 修复，以新文档为准。

## 操作

1. 在黑光模式下完成一次普通生物吸收，右上角会显示保存的身份。
2. 默认 **X** 切换为该身份；再次按 X 恢复主角本体。按键可在 Minecraft 控制设置中修改。R 已由 Epic Fight 占用，因此不用 R。
3. 保存的是**最近一次成功吸收的可用身份**。吸收新身份覆盖旧身份；吸收猎手、巨型目标或其他不可伪装目标不会擦掉已有身份。重进世界会保留身份，重生保留身份但恢复本体。

伸手抓取或被取消的吸收不记录身份，只有成功结算才记录。切换身份无需额外前置、进化点或生物质。

## 外观和过渡

使用目标自身的 Minecraft 模型、皮肤及外观变种，包含羊毛颜色、是否剪毛、村民职业、动物变种、幼体和装备外观。切换经过 16 tick 的组织覆盖和轻微收缩，在中间第 8 tick 更换身体，再退去组织。伪装期间收起武器与防御/感知能力；展开能力、抓取、攻击或发射弹射物会暴露身份。

伪装模型只在客户端绘制，不向世界添加实体、不复制 UUID、AI、交易、背包或掉落，也不获得对方的生命、攻击、技能。客户端接收服务端保存的身份和阶段，旁观玩家也使用同一外观。第一人称伪装期间隐藏主角手臂；第三人称能看到完整目标模型。

当前仍使用玩家碰撞箱和视点高度。变成小动物不会获得钻进小洞的能力，也没有新增生物专属操作。四足/双足模型使用各自移动姿态；需要专门动画状态的少数模型仍需试玩检查，不能视为整套生物动作已移植。

## 敌人识别

- 骷髅、僵尸等亡灵身份可骗过僵尸和骷髅阵营。
- 劫掠者等灾厄村民身份可骗过灾厄村民阵营。
- 普通动物身份可避开多数 Minecraft 怪物主动选敌；守卫者、蠹虫、末影螨、猪灵蛮兵不适用这条规则。
- 其他身份只按同实体类型匹配，不让所有敌人变成友方。Blacklight 感染生物和第三方敌人不受这套伪装免敌规则影响。
- 已有敌人盯着你且能看见你时，不能直接切身份消除追踪。暴露后警戒值增加，离开追踪视线后逐步消退，再允许伪装。普通行走、奔跑和被伤害不会主动暴露身份。

这是适配 Minecraft 的阵营识别机制，尚未包含军事基地门禁、指挥官权限、病毒探测器、记忆剧情或完整原作警戒系统。原作主要针对人类身份；这里变成动物和 Minecraft 怪物属于扩展。
