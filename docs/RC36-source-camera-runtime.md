# RC36 镜头与长变形

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.36。

本版把基础镜头的旋转、动作提示、六组长变形镜头和热能变形景深接入游戏。未感染及普通模式仍使用 Minecraft 生存动作；Epic Fight 和 GeckoLib 仍是前置。编译、打包与资源静态核对通过，实际观感尚待用户试玩。

## 本轮变化

- 地面、跳跃、爬墙、墙跑、受击、抓取和锁定分别处理镜头轨道。沿用原版十二份状态参数，接入已核对的角度限制、转向速率、跳跃延迟、小角度转向渐入及跌落高度范围。
- PC 鼠标调整后的自由角度在当前基础状态内保留，不再按手柄的短超时拉回。移动方向使用基础轨道角度，不使用震屏或电影镜头角度。
- 墙面转向使用实际墙面法线；地形碰撞立即收回镜头，空间恢复后缓慢拉远。电影镜头的混合路径也经过八条射线检查。
- 锁定构图考虑玩家和目标的实际包围盒。手动锁定优先；AutoTarget 提示只读取服务器已确认的攻击目标，不另行扫描或按生命值选择。取景不改伤害判定。
- 现有吸收、拳套、肌肉蓄力、刀锋下劈、拳套空中动作、地刺及空中连击，共 36 条动作时间线、78 个源事件。Jumping、Falling、Slide、Float、AutoTarget 提示可以同时存在，按对应身体阶段生效。
- 震屏池达到 32 个分量时，按原版衰减后平移/旋转振幅选择较弱分量替换，不再单纯删除最早分量。
- 新增利爪、刀锋、拳套、肌肉、鞭拳、热能视角六组长变形身体动画及各自默认自由游玩镜头。身体和镜头共享同步起点，保留原版的两段身体片段、位置/视线/上向量、FOV、进入退出时间。没有混入任务专用的替代镜头。
- 电影镜头具有帧区间、速度、首尾停留、跟踪、镜像、混合与中断退出支持；这六条实际路由均是原版确定的单一候选，无需随机选镜头。
- 热能变形按原版 DFEN 开关启用基于场景深度的景深。其他已接入镜头没有擅自打开模糊。渲染后恢复深度缓冲，HUD 不进入景深处理。

## 试玩入口

1. 感染并开启黑光模式，切换第三人称背后视角。
2. 按住 Z 打开轮盘，指向已解锁能力，停留半秒，看到提示后松开。站立且没有其他动作时播放长变形；快速选择仍直接切换。
3. 热能视角也可通过轮盘选择，或在它是最近一次感官能力时长按 H 半秒。短按 H 在松开时切换感官。
4. 移动、跳跃、攻击、受击、收起/切换能力会退出长变形；镜头用退出时间回接。单纯转动鼠标不会更改这段身体动作的固定朝向。

可以先观察长变形时身体和镜头是否同步，再看墙角、单格台阶、上墙/翻顶和锁定大型生物时的过渡。本次启动只打开已有测试存档，不自动执行试玩操作。

## 移植边界

这是一套读取原版数据、重建已核对算法并适配 Minecraft 的运行实现，不是将原版 DLL 或整个游戏引擎放进 Mod。以下差异不能称为一比一复刻：

- Minecraft 的角色中心、骨架缩放、碰撞体、鼠标灵敏度和实体尺寸替代原版引擎对象。电影镜头原点适配到玩家身体中心；FOV 适配为 Minecraft 垂直视角，远裁剪不越过本机区块渲染范围。景深用 Minecraft 后处理重建，没有移植原作渲染器。
- 普通镜头继续使用渲染帧历史积分；原版固定采样缓存、所有地形约束分支、控制器输入曲线及多候选电影镜头的遮挡评分没有逐句复刻。当前鼠标、碰撞和单候选流程已经接入，但不能因此声称全部原版镜头算法完成。
- 原版任务剧情、临界质量毁灭技及尚未接入身体流程的专用镜头没有接到普通攻击上。已解码不代表全部进入游戏。当前六组身体与镜头有明确对应关系。
- 拳套震地的未映射银行引用分支是蓄力条件，不是 RC35 文档误写的高度条件；此处纠正旧记录。当前仍使用已有命中反馈，不同时触发多个条件分支。原版带蓄力/目标条件而当前玩法没有该条件的镜头也没有强行启用。
- 为保留本 Mod 的操作取消，六种长变形均可被移动/战斗打断；部分原版镜头的 AbortWhenInterrupted 标记不同。未自动操作游戏验证观感。

## 资源与验证

本地动作资料共 222 份：RC35 的 215 份，其中 camera-events.data 更新为 78 条事件，另增六份身体动作和 camera-film.data。其余 214 份保持原样。私有片段、解包文件和原始 DLL 不上传公共仓库。

核对原版七种模式处理函数 0x1033ac30、0x1033b6b0、0x1033c4b0、0x1033cd40、0x1033dc50、0x1033ddf0、0x1033fed0，以及 PC 输入超时 0x10343540、提示 0x1033ec50、震屏替换 0x108c1110/0x108c14c0、电影/脚本镜头 0x1083c200/0x1083e4d0。动作路由在本地数据中记录源 owner、track 与时间映射。

执行 Java 编译与 assemble，核对 JAR 中的类文件、Mixin、222 份动作数据、着色器资源及版本；没有运行自动化测试或 GameTest。服务器与客户端需同时更新：协议版本 33。
