# 当前已知问题与收口清单

对应 0.2.0-rc.22，2026-09-26。状态是当前实现与待验收事项，不将历史测试结果当作本版通过。

| 优先级 | 项目 | 当前事实 / 放行要求 |
| --- | --- | --- |
| 待用户验收 | RC22 其他武器与全套核对 | 新增刀锋/重锤/鞭拳 9 个接招点；移动、抓取、玩家受击及镜头仍有未还原规则，详见 RC22 全表。 |
| 待用户验收 | RC21 原版接招时序 | 空手/利爪共 7 个明确 Input hook 接入运行时；保留命中窗口，完整原版条件和实际手感未验收。 |
| 待用户验收 | RC20 动作衔接 | 修复无能力切换拒绝路径，加入行进朝向、收招移动取消和蓄力跳跃取消；未游戏内确认全部反馈。 |
| 待用户验收 | RC19 水中上浮 | 修复黑光模式屏蔽游泳跳跃输入，入水取消陆地蓄力与预测，保留游泳动作；已编译打包，实际游泳和出水衔接待试玩。 |
| 待用户验收 | 铁傀儡及 Boss 吸收 | RC2 已接入名单、大型攀附、同步处决和 Boss 原生死亡分支；骨骼接触与结算尚未实玩验收，见 CONSUME_RC2.md。 |
| 阻塞（公开版） | 私人动画依赖 | RC17/RC18 本地试玩包已内置 199 个动作和配套数据；普通公开源码构建不含这些资料，不能声称等效。 |
| 待用户验收 | RC18 生存开局 | 已接入地图交易、冰下研究站、样本战利品与主动觉醒，移除普通材料配方。自然生成、入口可达、交易和重进均待实玩，见 RC18-survival-opening.md。 |
| 待实现 | 城市与军方 | 城市、黑色守望、超级士兵尚未实现；研究站内复用已有感染体模型，不能代表新怪物模型已经补齐。 |
| 待用户验收 | 全武器攻击 | 命中随动、各形态空中重击、组合技、打击反馈、无目标位移、近身与远程选敌。 |
| 待用户验收 | 移动与携带 | 墙跑朝向、头部不入墙、跳跃落地、快速携带随动、抛掷和中断恢复。 |
| 待用户验收 | 成长和蜂巢 | 生存获取、解锁前置、资源消耗、蜂巢奖励与刷新、退出重进。不得因已有类或界面而视为闭环通过。 |
| 待用户验收 | 升级界面 | 不同 GUI 缩放、窗口尺寸、底部项目可达、按钮和描述不重叠。 |
| 待验收 | 多人和性能 | 本轮不开展联机、压测或 GameTest；高延迟同步、配置一致性、大量特效的负载未在本轮验证。 |

本轮不实现真实地形破坏；当前裂纹和碎块是视觉反馈。后续若增加破坏，需要另行确定游戏规则和建筑保护行为。

早期设计槽位及动画维护记录保留于 [历史文档](history/pre-rc1-KNOWN_ISSUES_AND_SLOTS_ZH.md)，其中旧的未完成列表不再作为现状依据。
