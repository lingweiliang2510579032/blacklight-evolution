# RC8：吸收撕裂与组织回流

此前的 `ConsumeSeverance` 只在结束前缩小少量部位，没有实际分开模型；四足生物也没有部位处理。普通目标的回流触须在吸收后段才开始出现，造成目标完整消失的观感。

本版在命中时机之后裁切已经摆好姿态的模型表面，保留原贴图和 UV，补上深红黑色断面。各碎块先分离，再收缩、沿轨迹回流至施术者当前动画中的胸部接收点。网格处理不改变生物碰撞、生命值、奖励或共享模型部位。

- 利爪以上部断裂为主，利刃斜切，鞭拳横向断开，肌肉和铁锤分成四块；普通形态也有断裂回流。
- 命中之后出现黑色组织束、红色细脉和组织碎块。碎块先迸出，再回流；铁锤另有短暂的低位扩散环。
- 普通、Epic Fight 与本 Mod 的 Gecko 生物接入相同网格处理。Epic Fight 正在分裂的目标暂用 CPU 蒙皮获取实际顶点，不修改全局图形设置。
- 移除旧部位缩小和重复回流入口，抓取/持握阶段不会播放撕裂。末影龙保留原有独立翼部处理，加入统一回流特效；本轮没有把龙整体切成通用碎块。

这些是适配 Minecraft 的程序化视效，不是从原作提取的破碎网格或粒子。特殊模组自定义顶点格式不保证能分裂。

按用户要求仅编译打包，没有执行自动游戏内验收、截图脚本或 GameTest。启动最新版供用户亲自验收；编译通过不代表所有视角和物种的视觉效果已验证。
