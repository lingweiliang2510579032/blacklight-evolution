# RC31：方块护盾、破损重建与感知过渡

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.31。网络协议 28，客户端与服务端一起更新。

## 本轮变更

- 护盾正式替换为 54 个原创方块构成的阶梯甲壳，与 V4 装甲使用同一套自制像素材质。盾面有叠层、凸起中脊、侧刺和暗红组织缝。
- 完整、轻度破损、重度破损分别保留 54、44、32 块；打破后只保留 3 块前臂根部。缺损为实际几何缺口，按已核对的原版 60%、30% 盾值阈值切换。
- 继续使用已有解包展开、受击、跑步、疾跑姿态。补接手腕的相对旋转，修正盾面朝向；护盾跟随前臂和腕部动作。
- 模型从当前形状展开、收回；受击掉出盾面碎屑，越过破损档位时掉出被移除的甲壳。碎片约 0.9 秒后消失。
- 破盾时前臂保留附着根部，短暗红组织随重建进度脉动；重建完成后再展开。重建外观不会提前恢复格挡能力。
- HUD 显示破损档位，重建进度条计入 0.25 秒初始等待。装甲保持已确认的 V4 模型和生长曲线，新增受击反馈及硬化中的状态提示。
- 感染视角和热能视角加入约 0.2 秒淡入淡出，互换时先退去旧色调。热能目标按身体高度分层：躯干偏亮，末端偏红；燃烧目标更热，傀儡偏冷。**不根据剩余生命百分比调亮度。**

## 原版依据与适配边界

沿用 RC29 核对的 250 盾值、收起后治疗规则、恢复计时和装甲伤害倍率；具体来源见 RC29 文档。六条身体动作和装甲甲片生长曲线沿用私有解包数据。

方块盾形、缺损区域、几何生长、碎片轨迹、组织脉动、感知切换时长、热能身体配色均为 Minecraft 适配。并未移植原版护盾几何变形轨道、材质温度或完整视觉着色器。感知仍仅处理附近已加载的目标，保留深度遮挡；不是穿墙全图扫描。装甲甲片旋转、平移与剪切的还原边界沿用 RC30 说明。

本轮范围是防御和感知基础系统。军事科技、突袭夺取技术、实验室及超级士兵流程仍未完成，不能据此称全部内容已经完成。

## 资源和验证

原创模型源位于 `art/shield-block-v3/`，由 `tools/author_shield_block.py` 生成；运行模型为 `assets/blacklight/models/shield_block.json`。原版派生数据仍为 213 份，与 RC30 私有资料逐文件一致，仅随本地包提供，不提交公开仓库。

执行编译打包、资源结构及几何法线检查，并用导出的实际关节数据进行离线握持预览。没有执行自动测试、GameTest 或自动游戏验收。第三人称实际衔接、所有战斗姿态的穿插、光影模组兼容及联机表现仍需玩家试玩。

## 安装

安装包：`Blacklight-Ascension-MC1.21.1-NeoForge-0.2.0-rc.31.zip`。退出游戏、备份存档，替换旧 Blacklight JAR；保持 Java 21、NeoForge 21.1.244、Epic Fight 21.17.3.1、GeckoLib 4.9.2。不要同时安装新旧版本。已内置私有动作，无需外部动作路径。

当前正在运行的 RC30 实例不会热更新，重启并载入 RC31 后才能看到新护盾。G 开关上次防御能力，Z 轮盘选择护盾、装甲或感知能力。
