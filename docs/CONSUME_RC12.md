# RC12：恢复完整的吸收触手表现

用户明确要求保留黑光触手。RC11 将吸收束推迟到动作进度 70% 后才出现，且只沿短弧连接身体与胸口，表现不足。

- 触手在接触标记前开始生长，从主角胸口伸向实际绘制的受击方身体部位。
- 各部位生成粗细不同的两条触手，路径先延伸再沿部位周围缠绕；受击后逐渐收紧，末段随生物质回收消失。
- 使用连续管状网格与共享截面，每条由粗根逐渐收成尖端，加入沿路径运动的粗细脉动、黑色组织和暗红纹路。
- 缠绕半径来自当帧实际网格的部位尺寸，跟随肢体分离和缩小，不恢复站立高度的悬空特效。
- 保留 RC11 的短时运动碎屑、防重叠、吸收期间关闭目标描边和感染药水粒子修正。

这是本 Mod 的程序化触手适配，不声称使用了原版触手网格或完整恢复原版特效轨道。只编译打包和启动供用户试玩，未运行自动测试或游戏内验收。
