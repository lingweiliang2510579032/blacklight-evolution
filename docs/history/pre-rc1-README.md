# Blacklight Evolution 0.2.0-mvp.5

Blacklight Evolution 是一个面向 Minecraft 1.21.1 / NeoForge 的原创同人 Mod。这个版本交付的是可构建、可安装、服务端权威的第一条可玩闭环，不代表完整总转换内容已经完成。

## 参与开发

欢迎参与代码、模型、动画、特效和测试，见 [贡献指南](CONTRIBUTING.md)。公开协作仓库：[mengyuyuan/blacklight-evolution](https://github.com/mengyuyuan/blacklight-evolution)。项目原创内容采用 [GPL-3.0-only](LICENSE)。

R9 将感染后的僵尸转化为独立黑光猎杀者，并加入近身吸收；保留 R8 分阶段感染与玩家利爪展开/收回动画。可选接入 Epic ParCool 墙跑下肢动作，长爪上半身单独适配。试玩、依赖版本和制作工具见 [感染体试作说明](docs/INFECTED_PROTOTYPE.md)。

最近的 R7 改动将墙跑、慢速攀爬、静止抓墙和沿墙跳跃分开，并修正攀爬利爪靠近头部的问题。松开移动留在墙上，W/S 上下、A/D 横移，加速恢复墙跑，空格沿墙向上跳，Shift 离墙。动画表现和真实操作手感仍在迭代。

## MVP 可玩闭环

- 从“黑光进化”创造模式物品栏取得黑光病毒安瓿，右键投向地面；玻璃破碎后会感染投掷者与附近生物。`/blacklight infect` 仍可用于调试。
- `B` 在原版模式与虐杀原型模式之间切换。
- 进入虐杀原型模式后自动展开利爪；`V` 展开或收回利爪，鼠标左键触发三段连击。
- 长按鼠标右键播放利爪地刺动作；到用户保存的 2.2 秒终帧时自动释放地刺，等待地刺演出结束后将同一动作倒放复原。已经学会的技能释放不消耗生命质，生命质只用于学习/进化。
- 地面长按鼠标左键使用已解锁的冲刺斩；空中按鼠标左键使用空中斩/冲刺。
- 按住空格蓄力跳跃；蓄力动作只前进一次，满蓄力后定格在最终姿势并仅持续腿部黑光触手缠绕，松开才起跳。疾跑、贴墙攀行、滑翔可组合使用。
- 行走和奔跑使用完整八方向重心、腿部朝向、起步、刹停与转向衔接；切换方向不会重播脚步循环。
- 现有动作带有速度和命中强度驱动的物理反馈：蓄力起跳会爆开脚下尘土与生物质，疾跑产生受限的交替足迹，墙跑喷出接触碎屑，滑翔/空中冲刺形成黑红拖尾；落地按真实下落峰值分为轻、重、破坏性三级，并产生同步的安全裂纹、冲击环、声音、短镜头震动与 FOV 脉冲。
- 利爪一二段、第三段重击、冲刺斩与地刺现在拥有不同的方向性斩击轨迹、命中飞溅和冲击反馈。伤害、击退和命中数量仍由服务端裁定。
- `/blacklight grant_ep <数量>` 与 `/blacklight claw_upgrade <id>` 用于 MVP 验收升级。

利爪伤害、攻击窗口、生命质消耗和移动物理由服务端裁定。专用服务器登录时会把移动参数同步给客户端，避免客户端预测与服务器参数不一致。

## 双模式规则

| 模式 | 操作规则 |
| --- | --- |
| 原版模式 | 完整恢复 Minecraft 原版跳跃、鼠标、挖掘、建造、背包、工作台、箱子、熔炉和普通物品使用，同时强制 Epic Fight 回到 Vanilla 模式。黑光移动、战斗、模型与按键均不接管操作。 |
| 虐杀原型模式 | 自动进入 Epic Fight 战斗模式并启用利爪和黑光移动；禁止原版武器攻击、挖掘、放置、使用普通物品、拾取物品/经验、打开背包及工作台/箱子/熔炉等生存设施。按 `B` 返回原版模式。 |

模式状态由服务端保存并同步。旧存档没有该字段时会安全地进入原版模式。

## 黑光病毒安瓿

- 物品采用立体玻璃瓶、黑石封盖、红黑生物质内芯模型；手持、物品栏、掉落与飞行状态都使用同一模型。
- 右键投掷，撞击方块或生物后播放玻璃破碎、感染爆发音效和黑红粒子，感染半径为 8 格。
- 投掷者必定感染；范围内玩家成为可按 `B` 切换的 Prototype 宿主，仍从原版模式开始。
- 普通生物获得永久“黑光感染”：生命、移动、攻击和缓慢再生得到强化，会追击未感染生物。
- 感染体造成有效近战伤害时有 35% 概率继续传播，体现原作的接触与体液传播；普通生物不会直接获得玩家专用利爪与操作能力。

## 运行环境

- Minecraft 1.21.1
- NeoForge 21.1.244
- GeckoLib 4.9.2
- Epic Fight 21.17.3.1
- Java 21（源码构建）

客户端和服务器都必须安装 Blacklight Evolution、GeckoLib 与 Epic Fight。发布 JAR 不内置两个前置 Mod。

## 安装与启动

1. 把 `release/blacklight-0.2.0-mvp.5.jar`、GeckoLib 4.9.2 和 Epic Fight 21.17.3.1 放入同一个 `mods` 目录。
2. 启动 Minecraft 1.21.1 NeoForge。
3. 在“黑光进化”创造模式页取得病毒安瓿并投向地面；也可以执行 `/give @s blacklight:blacklight_sample`。
4. 按 `B` 进入虐杀原型模式；需要挖矿、合成或打开设施时再次按 `B` 返回原版模式。
5. 不需要手动按 Epic Fight 的 `R`；`B` 会同时同步 Blacklight 与 Epic Fight 模式。空中攻击为鼠标左键。

本项目包的 `config-presets/blacklight-animation-poses.properties` 是当前已经调好的蓄力跳跃与利爪地刺时间轴。要在新的 Minecraft 实例复现这套动作，请把它复制到该实例的 `config/blacklight-animation-poses.properties`；复制前先备份同名文件。当前版本的动作编辑器保存外部配置，单独复制 JAR 不会自动携带用户手调关键帧。

`F8` 移动调试器只允许在未开放局域网的单人世界使用；多人游戏中的参数由服务器控制。`K` 为利爪模型调试器。`J` 为模型优先的透明动作时间轴：人物上提供全部 20 根人形骨骼的小型拾取点；旋转模式提供红 X、绿 Y、蓝 Z 三轴旋转球，彩色环的拾取优先于附近骨骼点，拖球心可自由旋转；`W/E/R` 切换位移/旋转/缩放，`X/Y/Z` 锁轴，`F` 恢复自由轴，`Shift` 精调，`Ctrl` 让旋转吸附到 5°。`C` 开启下蹲联动，在人物上上下拖动即可同时驱动根骨、躯干、双髋、双膝与脚端。右上角的“视角归位”和“动作还原”可分别恢复第三人称背影视角、清空当前动作的自定义时间轴；对应快捷键为 `Home` 和 `Ctrl+Shift+R`，动作还原后可用 `Ctrl+Z` 撤销。所有操作都会在当前时刻写入完整的 P/R/S 关键帧，底部可拖动或播放时间轴。两种调试器都不改变战斗数值。

## 独立感染生物与吸收（R9）

僵尸感染异化结束后转化为独立的黑光猎杀者，使用自己的全身模型与近战 AI。原型模式下，近距离面对生命不足 30% 的猎杀者按 **E** 抓住后右键吸收，完成抓取吸收后回复生命、生物质和进化点。`/blacklight infected_sample` 生成试作生物。模型和动作仍是 Minecraft 风格的首版适配，具体功能、参考与验证见 [感染体与吸收说明](docs/INFECTED_PROTOTYPE.md)。
