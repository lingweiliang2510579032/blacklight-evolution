# RC35 原版镜头求解与动作事件

Minecraft 1.21.1 · NeoForge · Blacklight: Ascension 0.2.0-rc.35。

本版继续移植《虐杀原形》的第三人称镜头。已接入下面列出的源码重建逻辑与动作事件；**尚不能称为完整镜头移植**。原版七种基础镜头的全部旋转、地形约束、剧情镜头选择和景深还没有完成。编译与安装包静态核对通过，实际手感需要用户试玩。

## 已接入

- 十二种 ChaseCamSmoothingData 状态的全部 21 个字段：距离、仰角、水平/垂直前视、变化速度及减速区间。根据现有移动、墙面、抓取、锁定和受击状态选择。
- 原版标量逼近函数：减速区外匀速，进入减速区后指数趋近。替换 RC34 额外写死的 0.15 秒距离过渡。
- 原版抛物线历史权重与滤波窗变化规则。跟随三维位置，并在历史锚点穿过障碍时回到玩家当前锚点。
- 十种现有吸收身体动作对应的原版推近、光学缩放、重新瞄准、重叠事件接续和退出时间；普通、利爪、刀刃、拳套、肌肉、鞭拳及已存在的大型吸收变体共 37 条事件。
- 四种拳套攻击及其蓄力释放变体的八条震屏事件。合计 18 条动作路由、45 条源事件。
- 使用身体动画时钟触发。吸收恢复阶段沿用同一场景时间；利爪从原版第 45 帧开始的 FIG 时间，换算到当前完整身体片段后再触发。拳套使用 Epic Fight 的实际片段播放时间。
- Dolly 除以镜头距离；Zoom 除以 `tan(FOV/2)`，不直接对 FOV 角度做乘法。重叠推近从当时镜头值进入下一段。
- 原版 Small/Medium/Large 震屏档位：范围、强度优先级、距离衰减、传播延迟、振荡频率、随机分量、指数衰减及最多 32 个分量。已具有 FIG 震屏的动作不再叠加旧网络脉冲。
- 最终位置执行 Minecraft 八射线碰撞回缩。锁定镜头从这个最终位置重新瞄准当前锁定实体，选敌与伤害判定继续使用既有逻辑。
- 移除本模式下旧的跑步/爬墙正弦晃动、额外速度 FOV 和 Minecraft 行走摇晃，防止叠加。离开黑光模式、切换视角、传送、换世界、死亡等情形清理镜头状态。

RC34 的未感染/普通模式恢复生存动作与原生玩家渲染仍然保留。Epic Fight 和 GeckoLib 仍为前置。

## 与原版的边界

当前实现是已经恢复的原版数学与事件，加上 Minecraft 状态/碰撞适配。鼠标自由旋转和锁定转向仍由 Epic Fight 提供；本版的相对仰角、眼部锚点、锁定瞄准点和移动方向输入是 Minecraft 适配，不是原版完整 orbit solver 的逐句移植。

历史滤波使用 Minecraft 渲染帧采样及分段积分；原版用 64 槽定间隔环形样本。原版随机递推已实现，但随机种子归本 Mod 管理。未找到专属 FIG 路由的 Minecraft 命中/落地事件映射到原版通用震屏档位，该事件映射是适配，不应描述为原版原封不动的触发逻辑。

已在本地解析 67 条原版 CAM 片段及其位置、视线、上向量、FOV 等通道；**解析成功不等于已进入游戏**，这些片段没有打进本版安装包。它们包含任务、变身、特殊终结和剧情镜头，不能随意配到现有不同的身体动作上。电影镜头的候选选择、镜像、遮挡权重、景深、完整轨道混合及七种基础镜头的全部地形/角度求解仍待移植。

拳套震地的三个高度条件分支尚未纳入 FIG 路由，保留网络命中反馈到通用档位的适配。没有把条件分支合并为三个同时触发的震屏。源文件中的禁用分支也没有启用。

## 依据与验证

本地原版 DLL：标量逼近 `0x10336570`；抛物线滤波 `0x10335280`；状态处理 `0x10341fb0`；推近进入/推进/退出 `0x10343470` / `0x10341900` / `0x103418b0`；光学缩放 `0x1033a4e0` → `0x10338fa0`；震屏请求/档位 `0x1032d270` / `0x1032bf60`；振荡/包络 `0x108c15d0` / `0x108c0ff0`。

源派生设置与事件只放在本地私有动作包 `camera-profile.data`、`camera-events.data`，记录源哈希与帧映射。公开构建缺少私有数据时保留前置镜头；显式本地打包必须含完整资源。

只执行 Java 编译、assemble、资源/类文件一致性与差异静态核对；没有运行自动化测试、GameTest、自动游戏操作或把编译成功当作手感验收。安装包保留 Minecraft 版本和 Mod 版本。未自动启动或关闭游戏。
