# Blacklight 动作与大臂预览 r3

本轮覆盖项目当前已有的 20 段角色动作，替代 r2。参照《虐杀原形》一代实机片段重新编排姿势与节奏；这是 Minecraft 骨架上的重新制作，不是原作动作数据的逐帧移植。

## 实际查看的参考

- [Claw Power 实机演示](https://www.youtube.com/watch?v=k57rsOsSojo)：逐帧查看接近目标、挥爪、转身、冲刺及爪臂轮廓，细看 1–4 秒的挥击连续帧。
- [Claws & Ground Spike 高清演示](https://www.youtube.com/watch?v=qnbyGiuyh1k)：右爪蓄力插地、另一只手平衡、地刺破土。
- [蓄力跳跃与双空中冲刺](https://www.youtube.com/watch?v=iNVj0zWhK6s)：起跳伸展、空中收腿、张臂下落、落地缓冲。
- [墙面跳跃实机片段](https://www.youtube.com/watch?v=pOc_N7FnwNA)：交替蹬墙、离墙后的肢体展开、落地姿势。
- [CES 2009 吞噬演示](https://www.youtube.com/watch?v=jJQqXIfPPAo)：抓取、拉近、收臂吸收。此段是早期演示，不能据此断言所有细节都与正式版一致。

视频与截图只作观察参考，不打进模组。

## 修改范围

| 动作 | 本轮调整 |
|---|---|
| 待机 | 重爪自然下垂、双臂留出身体间距、肩胸轻微呼吸 |
| 步行、疾跑 | 保留脚步周期，重做大臂后摆、肘部弯曲和肩部带动 |
| 三段连击 | 右爪斜撕、左爪回撕、较大蓄力的重击；加入预备、出力、余势和收招 |
| 奔跑攻击、冲刺切割 | 身体前压、单侧先出爪、反侧平衡、动作结束时收回 |
| 地刺 | 保留单右爪和原有插地/保持/拔出时刻；调整左臂平衡与深蹲支撑 |
| 变形 | 提臂聚拢、组织展开、重爪落回身体两侧 |
| 吞噬 | 伸手抓取、拉近、收臂吸收、结束放松 |
| 蓄力跳跃 | 保留原有蓄力及释放逻辑，补充实际前臂关节的弯曲 |
| 起跳、下落 | 完整身体关节，从伸展起跳过渡到张臂、收放腿部 |
| 空中冲刺 | 收腿、身体前送、双臂后带、展开恢复 |
| 滑翔 | 展臂形成轮廓、轻微呼吸摆动 |
| 墙跑 | 接回本地循环，修改肩肘配合与爪臂间距 |
| 轻/重/毁灭落地 | 区分缓冲幅度，按屈膝幅度计算身体高度，减少陷地 |

连击、冲刺、起跳/下落和墙跑不再被运行时借用的双匕首、普通跳跃或攀爬动画覆盖。原有移动轨迹、移动时连击与服务器命中逻辑保留。

上臂横向尺寸比 r2 增加 26%，前臂增加约 31%，掌部另外略微放大。肩肘连接增加圆润的覆盖体积，避免弯曲时露出大块平面端盖。K 仍可分别调整左右手的粗细和爪刃长度。

## 检查方式

新增动作资源测试检查完整关节、四元数、严格递增的关键帧时间及服务器动作时长；接地检查覆盖地刺和三种落地的腿部支撑高度。

开发用截帧工具仅在显式传入 captureMotionPreview 参数时编译，且只允许在名称包含 Blacklight Motion QA 的存档副本中运行。正常 JAR 不包含该工具。

实机图片是客户端定格到指定关键帧后保存的原始截图，用来检查轮廓、连接和姿势。空中动作也固定角色位置，因此不能用这些图判断跳跃轨迹、实际连招手感或联机同步。完整的动态视觉验收仍需实际操作。

安装时用 r3 替换旧 Blacklight JAR，避免同时加载同 ID 的多个版本。
最终验证：Gradle build 通过，71 项测试，0 失败、0 错误。发布包包含 20 段完整角色动作，每段 20 个关节；已检查包内不包含开发截帧工具。副本客户端完成 23 张关键帧截图并正常退出。
