# RC42：原版血条、跳跃与战斗数值

Minecraft 1.21.1 / NeoForge / Blacklight Ascension 0.2.0-rc.42。

## 原版 HUD 素材

本地包新增 `health-hud.data`，从用户本机解包的 `fe_ingame.p3d.rz` 提取原版心脏图标、连接端、细条与心电贴图，并从 `protohud.gfx` 核对 healthHUD 的位置、比例、颜色和透明度。当前渲染使用心脏、连接端、细条，以及源 GFX 的矩形血量填充。原来的粗胶囊式生命条被替换，数字仍在 U → 属性页。

受伤缓退由 Mod 血量驱动，Minecraft 额外吸收生命以独立青色细条表示。未移植原版整套 Flash 脚本、升级演出或 Critical Mass 系统；心电贴图虽已提取，本版尚未播放其源时间线。源码保留无私有素材时的简单回退血条。本地素材预览不等于游戏内截图。

原版派生素材仅放在私有构建目录，不写入公开 `src/main/resources`。新增一份 HUD 数据，原有 222 份动作/镜头文件不变。

## 跳跃与空中动作

旧配置最大力度 3.0，再乘满级 1.75，最终初速度 5.25 格/刻；按标准重力和阻力估算能上升约 97.6 格。此前的参数范围与升级相乘，导致高度失控。

| 项目 | RC42 |
|---|---|
| 默认点按 / 满蓄力初速度 | 0.55 / 1.25 格每刻 |
| 默认蓄力时长 | 24 刻（1.2 秒） |
| F8 点按力度范围 | 0.30～0.80 |
| F8 满蓄力力度范围 | 0.80～1.65 |
| 跳跃强化 I / II / III | 起跳速度 ×1.10 / ×1.20 / ×1.30 |
| 最终起跳速度硬上限 | 2.20 格每刻 |
| 默认未升级点按 / 满蓄力预计高度 | 约 2.0 / 8.8 格 |
| 默认满级点按 / 满蓄力预计高度 | 约 3.3 / 14.0 格 |
| F8 拉满且满级预计最大高度 | 约 22.6 格 |

F8 和 U 属性页显示含升级的预计跳高；估算不包含碰撞、药水和其他 Mod。旧配置加载时将超出新范围的跳跃值限幅，其他 F8 参数保留；本次未改写正在运行实例的配置文件。主动恢复默认值时会使用上面的新默认参数。

每次重新进入起跳/墙面动作，重置对应一次性片段的时钟；保留步行/跑步连续步态。短起跳片段播完后，平滑接入已有原版空中循环，避免长时间夹在末帧。离地时清除残余落地恢复状态。没有修改私有动作文件或再加一层物理位移。

## 战斗尺度与目标

基础感染者保持 100 生命，生命成长仍为 150 / 225 / 325 / 450；敌人生命与玩家输出沿用 RC40 单位。普通敌人应造成消耗，精英需要闪避，首领保留高威胁。不能简单将所有承伤乘五后就认为平衡完成。

生物造成的伤害，在进入护盾和护甲处理前按攻击者类别调整：普通生物 ×0.30；猎杀者、变异体及列出的精英 ×0.40；首领 ×0.50。后续仍只执行一次生命单位换算。

以下为普通难度、100 生命、无护甲/护盾/抗性、无治疗的参考：

| 攻击 | 之前每击 | RC42 每击 | 理论致死次数 |
|---|---:|---:|---:|
| 普通僵尸（基础伤害 3） | 15 | 4.5 | 23 |
| 感染宿主（基础伤害 5） | 25 | 7.5 | 14 |
| 追猎变异体近战（基础伤害 5） | 25 | 10 | 10 |
| 猎杀者（基础伤害 7） | 35 | 14 | 8 |
| 重型变异体（基础伤害 10） | 50 | 20 | 5 |
| 喷吐弹（基础伤害 4） | 20 | 8 | 13 |

这些是数值计算，非游戏实测。难度、附魔、护甲及群体攻击会改变实际结果。困难难度僵尸约 6.75、猎杀者约 21、重型约 30，仍高于普通难度。

另设单次生物攻击的基础伤害预算上限（换算成当前生命单位、护甲前）：普通 10，普通生物爆炸 28，精英 22，首领 40；简单难度预算 ×0.75，困难 ×1.5。伤害本身已由 Minecraft 处理难度，代码只按难度改变上限，不再重复乘伤害。这样小怪的高附加伤害不会突然超过精英一大截，爆炸仍需躲避。群攻次数与攻击间隔不受上限保护。

分类按实体类型而非最大生命：本 Mod 猎杀者/变异体、劫掠兽、铁傀儡、猪灵蛮兵、远古守卫者为精英；蜂巢、监守者、凋灵、末影龙为首领。其他生物默认为普通；其他 Mod 的自定义首领尚无专门分类。

投射物按其生物发射者分类。未感染玩家、玩家对玩家攻击、环境伤害和虚空不套用这套生物承伤调整。装甲再乘 0.525；护盾按调整后的同一伤害消耗耐久，不会先扣高伤害再只减血少量。生命成长不会提高怪物伤害。原有吸收回血与战后再生继续使用新生命单位。

## 验证和交付

Java 编译、assemble 与安装包静态一致性检查；未运行自动化测试、GameTest 或自动化游戏操作。需要游戏内试玩确认空中连续动作、伤害手感与 HUD 观感。当前 RC41 游戏不会被强制关闭；本包须下次启动加载。网络协议仍为 35，客户端与服务器应一同更新到 RC42。
