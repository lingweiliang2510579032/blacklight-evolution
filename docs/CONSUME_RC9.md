# RC9：受击方动画

本地候选版，等待用户试玩；本轮仅编译打包，不运行自动测试或游戏内验收。

## 受击方数据

之前的动作解码主要来自 Alex 主角资源，不能代表全部 NPC 动作。本轮从本机原版 Brawler 资源和 startup 内的 NPC 骨架中提取对应轨道，并为感染猎手接入左右受击、左右重击、正面重击、利爪受击、挑飞、砸地、倒地姿势、起身、死亡以及抓取和吸收。15 个运行时片段中，倒地保持使用起身动作的首帧，其余使用动作时间序列。

猎手受吸收使用 Brawler 骨架上的 alex_brawl_consume_2_rcv，与主角给予方配对。按同一实际时间播放，受击方结束后保持末帧到主角收招，取消之前人为固定双腿和过早缩小身体部位的处理。此版猎手使用原版现有的这一组成对吸收，不声称具备每种武器各自的猎手吸收。

8 段已有原版人形受击轨道也接入普通模型和 Gecko 模型；Minecraft 四足生物采用骨架适配，不能视为原版四足动物动画。利爪终结攻击可触发猎手专用利爪受击。地面重击不再在仅 3 tick 后强制切到倒地，猎手起身使用对应源动作时长。

## 裂解和特效

裂解延后到吸收末段的生物质转换，先让受击方完整身体动作播放。伤口截面按独立闭合轮廓生成，避免不同肢体被一个大盖面连起来；碎块先缩小再回收，减轻大块身体穿过主角的情况。

## 范围与交付

新增 receiver-poses.data 包含 23 个片段，单独随本地私有动作配置交付。映射关节及其父节点的解码错误会中止导出；未使用的手指通道记录在私有清单中。这不是对所有 NPC 或所有源通道已完整解码的声明。原版派生数据不包含在公开源码或 Mod JAR 中。

骨架比例、接触位置和游戏内最终观感尚需用户试玩确认，编译成功不代表视觉验收通过。
