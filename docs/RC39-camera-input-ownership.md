# RC39 镜头侧面锁死与控制衔接

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.39。

用户反馈镜头有时停在侧面，鼠标转不动或刚转就被拉回，整体操作不顺。本轮检查了鼠标输入到球面镜头、目标锁定、自动取景和移动状态切换的路径。

## 已修正的代码路径

- 目标镜头分支之前在应用鼠标输入前直接清空水平/垂直增量，有效锁定时无法手动绕转。现在先应用一次鼠标输入，再清空，避免重复转动；手动调整后不会立即被自动视角锥拉回原侧面。锁定目标仍保留，画面仍将人物与目标纳入取景，Tab 仍用于解除锁定。
- 前置的锁定标记和目标是否有效可能脱节。现在角色替换、退出世界、目标死亡/移除/离开当前世界或黑光模式退出时，清除失效的镜头锁定，并同步服务端目标。渲染端也只在目标有效时进入目标镜头分支；即使目标在 tick 与渲染之间消失，也不会吞掉鼠标输入。
- 之前地面、跳跃、受击等状态切换会无条件清掉手动镜头控制。现在保留用户选定的镜头方向，避免复杂地形或受击后自动跟随突然接管。新进入显式目标锁定时仍允许自动取景，鼠标转动后由用户控制绕转。

这是为 Minecraft 高频地形/受击状态切换做的控制衔接适配，不宣称与原作状态机逐条完全相同。墙面镜头的表面约束、碰撞回缩、动作震动和长变形镜头仍按现有流程工作。

## 交付和验证

本版包含 RC37 的步态、镜头及 F8 修复和 RC38 的重生/重进世界动画恢复、E 抓取修复。没有调整用户的 F8 参数、鼠标灵敏度或移动速度。

网络协议仍为 34；222 份私有资源与 RC38 保持一致。执行 Java 编译、assemble、安装包类文件/资源核对和 Git 空白检查。未运行自动化游戏操作或手感验收，也未关闭用户当前游戏；需退出并加载 RC39 后由用户试玩确认。
