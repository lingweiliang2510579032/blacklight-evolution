# Blacklight Evolution 0.2.0-mvp.5 验收清单

## 一、安装

客户端与服务器均使用 Minecraft 1.21.1、NeoForge 21.1.244，并安装：

1. `blacklight-0.2.0-mvp.5.jar`
2. GeckoLib 4.9.2
3. Epic Fight 21.17.3.1

三个 Mod 的版本必须一致。进入世界后从创造模式“黑光进化”页取得病毒安瓿，或执行 `/give @s blacklight:blacklight_sample`。

## 二、病毒安瓿与感染

1. 物品栏和手持状态应显示立体玻璃瓶、黑色封盖与红黑病毒内芯，不能显示紫黑缺失模型。
2. 右键投向方块或生物；撞击后应播放玻璃破碎与感染爆发声，并出现瓶体碎片、黑烟和红色孢子。
3. 投掷者必定感染，8 格球形范围内的存活生物也被感染；动作栏显示首次感染数量。
4. 玩家感染后保持原版模式，并提示按 `B`；普通生物显示暗红感染粒子，生命、移速、攻击与再生提高。
5. 感染生物会主动接近未感染生物，造成伤害时有概率继续传播；已感染目标不能被重复计数。
6. 退出世界再进入后，普通生物的永久感染效果与玩家的黑光状态都应保留。

## 三、双模式

1. 感染后保持原版模式：可以正常跳跃、挖矿、放置、打开背包、工作台、箱子和熔炉。
2. 按 `B` 进入虐杀原型模式并展开利爪，Epic Fight 应自动进入战斗模式。
3. 该模式下尝试挖矿、放置或右键工作台/箱子/熔炉应被阻止并显示提示。
4. 该模式下背包/合成界面不应打开，普通物品不能使用，地面物品与经验不能拾取，原版武器攻击不能生效。
5. 再按 `B` 返回原版模式；Epic Fight 同时回到 Vanilla 模式，利爪模型、黑光动作、加速和鼠标拦截应停止，上述生存操作全部恢复。
6. 退出时超过原版范围的水平速度应被收敛，不能把黑光高速带回原版模式。

## 四、核心战斗

1. 感染后利爪自动展开，`V` 可收回和再次展开。
2. 展开利爪后静止或普通移动时短按鼠标左键，应依次播放三段利爪连击动作；奔跑中短按左键应无停步地衔接奔跑斩。
3. 每段攻击只在服务端活动窗口结算一次；基础伤害依次为 7、8、11。
4. 展开利爪后长按右键蓄力，右侧利爪向脚边地面插下后松开；地刺仅能在地面释放，不消耗生物质，并在玩家前方远处向上爆发。双腿不能向后踢，身体不能形成后撅姿态。
5. 执行 `/blacklight grant_ep 250` 和 `/blacklight claw_upgrade dashing_slice` 后，在地面长按鼠标左键约 0.35 秒可触发冲刺斩；短按仍为普通连击。
6. 执行 `/blacklight grant_ep 200` 和 `/blacklight claw_upgrade damage` 后，利爪技能伤害提高 25%，普通攻击与其他来源伤害不应被放大。

## 五、移动

1. 按住空格蓄力，双臂应随蓄力逐步向后抬且根骨保持正立；蓄满后继续按住会维持终点姿态并在双腿显示黑红缠绕触手，松开才跳出。蓄力时走下方块边缘应取消蓄力并正常下落，不能悬空。
2. 按住前进和疾跑时应逐步加速，速度受服务器参数上限控制。
3. 空中按住跳跃靠近正前方墙面时可攀行；下落时按住跳跃可滑翔。
4. 利爪展开时，离地后按鼠标左键可触发一次空中斩/冲刺，落地后恢复。
5. Epic Fight 默认 `R` 战斗模式与本 Mod 的鼠标攻击分流互不冲突。
6. 蓄力起跳应按蓄力强度喷出脚下尘土和黑红生物质；疾跑足迹必须左右交替且数量受限，墙跑接触面应有方块碎屑，滑翔和空中冲刺应留下短促黑红拖尾。
7. 从不同高度落地时反馈应有明显分级：普通小跳不触发冲击，轻落地有小尘圈，重落地和破坏性落地具有更宽的冲击环、低沉声音和短镜头/FOV 脉冲；同一次落地不得每 tick 重复触发。
8. IDLE/WALK/RUN 之间不得因单帧速度或疾跑标志波动反复切换；基础移动与攻击动作应使用混合过渡而非硬切复位。
9. W/A/S/D 与四个斜向必须产生对应重心和腿部朝向；跨方向边界不能来回抽动，切换方向不能把脚步重播到第一帧。
10. 蓄力释放后必须经过上升与下落动作；轻、重、破坏性落地使用不同姿态，重/破坏性落地分别只有 3/6 tick 短减速且攻击可取消。
11. 重落地裂纹只由临时粒子构成并同步给追踪客户端，不得修改、替换或删除任何方块。

## 六、战斗物理反馈

1. 利爪一、二段应显示较窄的方向性斩击轨迹；第三段应有更宽、更低沉的重击反馈。
2. 只有真正造成伤害的命中才触发目标处黑红飞溅和动作发起者镜头冲击；挥空仍保留斩击轨迹，但不得伪造命中反馈。
3. 冲刺斩和地刺应具有强于普通连击的冲击反馈，但不得改变服务端攻击窗口、基础伤害或最大命中数量。

## 七、多人一致性

1. 客户端登录专用服务器后，服务器发送移动参数快照。
2. 客户端预测使用该快照，避免因本地配置不同产生持续位置回正。
3. 专用服务器或开放局域网的世界按 `F8` 不应打开移动调试器；未开放局域网的单人世界允许使用。

## 八、自动验证

在源码根目录使用 Java 21 执行：

```powershell
.\gradlew.bat clean build --no-daemon
```

构建必须通过，测试报告位于 `build/reports/tests/test/index.html`，发布物位于 `build/libs/blacklight-0.2.0-mvp.5.jar`。
