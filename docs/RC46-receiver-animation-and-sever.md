# RC46 受害者动作与刀锋分体

针对“被抓/被吸收的生物没有对应动作”的反馈，本版修改受害者模型和分体渲染。

- 为鸡、马/驴/骡、狼、猫、狐狸、兔子、羊驼等非 Hierarchical 模型取得具名骨架。受害者片段按照当前武器和双方共享的场景时间驱动头、四肢、翅膀；保留物种关节位置和初始角度。四足动物不再把肢体动作统一压到 45%。
- 递归处理嵌套关节，按父骨骼消除重复旋转。普通模型直接使用已经导出的受害者投影，不再依赖 Epic Fight 的人形 Pose 是否可采样来决定播放。
- 只有确实绑定到关节才报告应用成功；加入按实体/阶段/模型去重的 `Receiver pose applied` / `unbound` 日志。羊毛等复制层使用相同绑定和身体分区。
- 刀锋普通吸收将实际几何切为两半，包含躯干切口、断面封口、整块分离与回收；不再只拆头和四肢。四足动物切割轴适配其水平躯干。大型攀附和猎手专用吸收保留自己的分支。
- 利爪当前使用的是 crush_head 片段，其碎裂类型由通用撕臂改为头部压缩。

## 原版依据

本地 `startup_fig.p3d` / `alex_fig.p3d` 中 `prototype_consume` 的刀锋 receiver 节点使用 `alex_grap_blade_spin_and_slice_rcv`：动画有效区间约 0–0.933333 秒；约 0.833333 秒同时出现两条 `spawnGib`、`primitiveDisplaySimple`、`setVisibility` 记录，1.33333 秒出现 `consumeMe` / `death`。原版受害者表现由身体动画、生成碎块、切换显示和吸收事件共同完成，不能把短 receiver 动画补长后就视为完整移植。

RC46 使用 0.833333 秒的分体时间，归一到当前刀锋片段时钟。两条 spawnGib 的时间取自记录字段，并有同时刻显示切换记录交叉印证；碎块资源哈希、生成轨迹等字段尚未完整解明。因此本版几何切割方向、分离轨迹、回收阶段仍属于 Minecraft 适配，不是原版碎块资源或完整逐帧移植。

其他原版 receiver 节点中，利爪 footsweep、肌肉 arm_rip、鞭拳 come_here 也有两条 spawnGib；它们并不意味着所有武器都使用刀锋的腰斩。当前鞭拳包实际使用 lash，尚未接入 come_here 切换；利爪 footsweep 等候选动作轮换也不在本版范围。动物骨架是适配，原作没有 Minecraft 猪、羊、鸡的专用片段。

## 验证边界

仅编译、打包和核对包内容；不运行自动测试、GameTest 或自动游戏验收。保留 RC45 空中攻击、冲刺、水面起跑修复，使用与 RC42 相同的 223 份私有动作/配套文件。

本地试玩重点：刀锋吸收僵尸/猪时是否出现两块躯干；切口和羊毛是否对齐；切换武器抓取、吸收鸡/马/兔/羊驼时头和肢体是否持续播放；动作结束后其他同类生物是否恢复正常。实际观感、断面和不同体型接触仍待用户试玩。
