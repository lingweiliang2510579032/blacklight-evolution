# R17：按用户确认的生成图重建刀臂

用户明确选择重新上传的“双端刀臂·建模参考”，并补充“刃连接在一起”。此前将反馈理解为否定生成图、进而缩窄刀臂，是错误的方向。R17 以这一澄清为准。

## 几何

- 上挑刃、中段和宽下刃由同一段连续截面网格组成，部件名为 `R / continuous double-ended blade`。没有用筋束代替中段的实体刀身。
- 一大一小的椭圆镂空使用有厚度的环形网格，内部是真实空洞。
- 刀根以不对称层叠硬壳和深红组织分支连接手臂；保留长刃的窄刃口和背部厚度。
- `tools/build_blade_r17.py` 使用参考图正面轮廓的设计平面坐标制作网格。`tools/build_reference_weapons.py` 的 `blade()` 调用该入口，其余形态保持 R15。
- 实际模型的正面、背面和斜侧视由 `tools/render_blade_sheet.py` 渲染，三幅是同一网格。参考图标注的“侧面”本身是斜侧视。

## 绑定与验证

刀面安装角为 30°；吸收时调整右前臂绕自身轴的旋转，保持起始抓取姿态、动作长度和服务端吸收时机。最接近头部的采样间距为抓取 0.069、吸收 0.0768 个骨架单位。美术还原程度应对照参考图及实际模型判断，不能由构建或避头检查代替。

旧 R15、R16 的试玩包与记录保留用于对比，不作为本次造型标准。
