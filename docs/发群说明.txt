《虐杀原形》Blacklight: Ascension — Minecraft 1.20.1 Forge 完整安装包
版本：0.3.0-forge-1.20.1-dev.3
原作者：末者；Forge 移植维护：雨夜。

本版已同步作者 Forge 专用分支，包含抓取生物后按镜头方向转向和双人姿态插值修复，以及完整的224个动作、镜头、HUD资料。

安装：
1. 使用 Minecraft Java 1.20.1、Java 17、Forge 47.4.10。
2. 将压缩包 mods 文件夹中的 bundled.jar 放进对应游戏实例的 mods。
3. 另装 GeckoLib 4.8.4，必须选择 Forge 1.20.1 版。
4. 删除旧 Blacklight JAR，避免重复加载。MixinExtras 已内嵌，无需另装。
5. ParCool 可选；不需要 Epic Fight、Epic ParCool 或 Weapons of Miracles。
