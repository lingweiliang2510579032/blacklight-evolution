# 0.2.0-rc.1 本地候选版

日期：2026-09-22。阶段：功能冻结候选，等待用户验收。本轮不增加新的武器、敌人或玩法系统；优先处理收口清单中的阻塞问题。

## 已接入的本轮变更（不代表试玩已通过）

- 地面普通攻击不再因远处锁定目标自动跑过去；空中追击与无目标飞踢等位移攻击分开处理。
- 刀臂体积、双端刀刃轨迹和实际命中反馈调整。
- 攻击接触环境时按接触位置生成材质碎屑、尘土和声音；冲击碎片临时存在，不破坏真实方块。
- 武器攻击距离基础扩展及三档距离升级；鞭拳抓取仍独立固定为 12 格。
- 升级界面移除覆盖文字的背景模糊，加入滚动、换行和窄窗口布局。
- 抓取规则统一为最大生命 <50 直接抓，>=50 需当前生命 <=15%；被动动物不再豁免。开始吸收时再次核对血量。
- 补充劫掠兽、监守者、守卫者、远古守卫者、炽足兽进入当前可吸收名单。

## 本轮收口产物

- 版本号固定为 0.2.0-rc.1，替换长期未更新的 mvp.5 标识。
- README、已知问题和用户验收表统一到当前事实；旧说明保留历史副本。
- 本地候选包：Mod JAR、构建日志、动画/参数与 Blacklight 配置快照、依赖指纹、SHA-256 清单。
- 不包含存档和第三方依赖 JAR，不进行上传。

## 放行条件

1. 补齐已讨论的铁傀儡及 Boss 吸收规则，尤其末影龙的多部件目标、死亡与世界进度结算；不能仅把实体名字加入名单就算完成。按用户补充，吸收演出需独立按体型分支：普通目标抓持，大型目标让玩家攀附目标，再按形态执行处决/吸收；切割部位属于需单独核对原作并适配的演出，不将所有大型目标缩放后套用手持吸收。血量门槛与体型/骨骼演出分类分开。
2. 用户完成 ACCEPTANCE_RC1.md 的关键试玩项，反馈的问题修复并由用户复验。
3. 如准备公开发行，需另行确定可以分发的动画方案，核对完整客户端/服务端依赖、旧档兼容和多人行为。当前仅本地快照，不宣称公共整合包可复现本机表现。
