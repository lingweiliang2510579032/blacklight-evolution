# R16 刀臂轮廓修正

R15 的游戏刀臂被用户否定。R16 尝试收窄轮廓，但再次被否定。用户随后明确认可生成参考图，并要求上下刀刃连成一体；后续以 R17 中记录的这一澄清为准。下文仅保留 R16 的实现记录。

- 前向刃的最大宽度从中段移到手腕根部，末端持续收尖；刃面改为薄的折面与窄刃口。
- 反向长刃沿前臂外侧生长，连接回同一刀根，移除远离手臂的大弓圈和细杆桥接。
- 收紧上臂及肘部体积，以交叠硬壳连接前臂与刀根，暗红筋束集中在根部。
- 移除 R15 的强制平举待机覆盖，使用正常待机姿态；前刃长度改为适合该姿态的比例。
- 刀面绕前臂朝外安装，并重新调整刀臂吸收时的前臂旋转，保留抓取起始姿态及吸收时间。其余三种武器保持 R15。

生成入口仍为 `tools/build_reference_weapons.py` 中的 `blade()`，该网格的 `designRevision` 为 16。

验证：88 项现有单元测试通过，包含四种形态在抓取、持有、投掷和吸收动作中的网格避头检查。刀臂安装角为 -60°，吸收前臂滚转修正为 +45°；骨架采样的抓取最小头部间距为 0.1126，吸收为 0.1026。构建通过，试玩 JAR 排除开发截图与 GameTest 类。

这是基于用户给定概念图的修正版，不能把测试通过当成美术还原验收。前后对比与游戏截图随本地试玩包保存。
