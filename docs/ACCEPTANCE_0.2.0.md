# 0.2.0 人工验收表

适用候选：**0.2.0-rc.57** · Minecraft 1.21.1 / NeoForge 21.1.244。当前所有条目均为 **待验收**。表格描述应检查的行为，不声称已运行或通过；RC54～RC56 的局部试玩反馈不自动算作本候选通过。

仅在用户明确要求后执行游戏或自动验证。本表供用户按需试玩；源码编译、资源静态检查和人工验收分别记录。公开资源授权与默认构建缺动作属于发布阻塞，不能靠私有包试玩消除。

## 记录方式

每次记录实际 JAR 完整文件名与 SHA-256、Java/前置版本、资料类型、存档副本名、世界类型/种子、难度、游戏模式、关键配置、参与者、日期和结果。结果使用“通过 / 失败 / 阻塞 / 未执行”，附日志时间与截图。发现失败后记录复现步骤和修复版本，再在修复版本复验。

生存获取与成长节奏必须在不赠送 EP、不调加速的独立存档副本中检查。能力覆盖可另开管理员场景，明确标记用了哪些指令，不能将两者混为一次通过。
