# RC19：黑光模式水中上浮修复

用户反馈：黑光模式进入水里后，按跳跃键不能上浮。

原因：`KeyboardInputMixin` 在黑光模式下无条件清除原版 `Input.jumping`，用于避免普通跳跃抢在蓄力跳之前触发；原版游泳也依赖这个字段施加上浮力。服务端跑酷控制器本来就会在水中退出，结果两个系统都没有接管上浮。

现在水和岩浆中保留原版跳跃输入；客户端入水时取消陆地蓄力、解除动画暂停并停止墙跑/冲刺预测，出水后重新同步按键。服务端也禁止在流体中因输入包触发蓄力或释放。流体中的陆地动作状态清除，保留 Epic Fight 自身的游泳动作。

不额外添加上升速度，不改变存档、能力进度、前置依赖或消息格式。保留 RC18 内容及 199 个本地动作和三份配套数据。

验证：Java 21 执行 `clean assemble` 通过，核对包内版本、修复类与动作数据。按当前项目约定未运行自动测试、GameTest 或游戏内验收。替换旧版 JAR 并重新启动游戏生效。

待试玩：黑光模式深水中按住空格上浮、站在浅水底上浮、蓄力期间入水后松键、出水后再次蓄力。普通模式应保持原有游泳行为。
