# RC27：墙顶交接与低障碍翻越

## 原版资料核对

本地 P1 解包资料区分慢爬上沿、疾跑墙顶出口与疾跑越过低障碍：

- `alex_climb_ledge_up` 在 `prototype_wall` 的 climb 分支，现有 `basic_wall_mantle` 对应此片段。
- `prototype_wall` 的 wall_run / exit / exit_edge 下有 parkour_exit 分支，包括左右跨步、收腿跳、侧翻等；另一 pose 分支 owner 83276 使用 `alex_wall_run_top`，FIG 时长 0.6 秒，源末帧为 12。
- `prototype_sprint` 的 obstacle / parkour / avoid / entry / pose 下有左右跨步、`small_basic`、`small_basic_B`、跨栏与滑过车头等片段。owner 84540 使用 `alex_loco_parkour_small_basic` 的 0–25 帧，时长 25/30 秒；owner 87108 的跨栏分支还带 obstacleHeight 条件。

这些证据确认了分支及片段用途，不代表已视觉验收每个动作，也不将尚未完整解码的条件当成确定的 Minecraft 方块高度阈值。新增两个本地私有片段：`basic_parkour_small` 与 `basic_wall_top`；导出沿用既有骨架重定向与根位移剥离方法，Coord 只作诊断，不驱动物理。

## 本次实现

一格以内仍交给原生步高处理。疾跑遇到高于一格、最多 2.05 格且有可到达顶部的障碍，直接进入短翻越，使用 small_basic 片段；避免先将身体转到墙面奔跑再立刻切回地面。真正的墙面仍按原有攀爬/跑墙处理，接近顶部后区分慢爬 MANTLE 与疾跑 TOP。

墙顶探测先检查身体向上的空间，再检查前移路径和目标脚下支撑。翻越的向内与向上速度仍经过 Minecraft 实际碰撞；不传送、不穿过天花板，也不把步高整体增加到两格。

旧实现固定执行 7 tick 翻越后退出，退出时无条件播放下落。新实现记录目标平台高度，直到实际 onGround 且身体中央脚下有支撑才交回地面；20 tick 只作为受阻或目标失效时的退出上限，不制造落地。落脚后直接选择跑步、走路或站立，翻越中保留疾跑意图，并消除落脚时步态过滤器短暂插入 IDLE 的情况。

地形短翻越及普通墙顶出口不再触发重型翻越的镜头冲击。离墙时保留旧墙面朝向 4 tick，让动画混合过程中仍能正确采样离场姿势，避免墙面姿势突然随镜头旋转。

一/两格分流、速度、探测范围、物理接地时机及提前接回跑步属于 Minecraft 适配。并未还原原作完整跑酷分支、随机变体选择或全部动作状态机；片段播放与碰撞进度也不是原作引擎的逐帧复现。
