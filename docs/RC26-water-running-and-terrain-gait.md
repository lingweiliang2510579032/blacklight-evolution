# RC26：水面疾跑与地形上的跑步动画

用户反馈普通地图主要是动画抖动，实际移动速度正常。本轮同时加入水面疾跑，并修正小高差造成的动作切换。

## 水面疾跑

感染且处于黑光模式、保持疾跑并有水平速度时，水面提供仅对该玩家生效的碰撞支撑。使用水的实际表面高度（另加 0.002 格避免浮点接触抖动），适用于静水和非垂直下落的浅层流水；不修改水方块，也不影响其他生物。客户端和服务端使用相同资格与碰撞代码。

停跑、速度降下来或潜行后恢复入水。水下不会自动吸附到水面，仍使用正常游泳与空格上浮。岩浆、瀑布、飞行、乘骑、死亡以及正在占用身体的武器/抓取吸收动作不启用水面支撑。水面脚步使用水花和泼水声，避免沿用陆地碎块、烟尘与落地震波。没有添加水下冲出水面的新动作。

## 跑步动画连续性

- 原先 `onGround` 短暂变为 false 就进入 FALL，并暂时交还身体朝向。现在只有刚从地面进入、向下小幅运动、脚下 1.05 格内仍有碰撞支撑且不超过 6 tick 的移动，才在视觉上维持步态。实际跳跃和悬崖仍正常进入空中动作，不修改物理落地状态、坐标或重力。
- 一格台阶原先可能被 0.78 格高的躯干射线识别为墙面。现在先核对抬升路径与前方空间，让可正常跨过的低台阶交给原生碰撞处理，真实墙面和低天花板仍保留限制。
- 小下坡不再反复清除疾跑标记，避免每次接地重播起跑反馈。移除服务端单独施加的撞墙减速，阻挡仍由原生碰撞负责；护甲疾跑上限在客户端预测中与服务端保持一致。
- 本地动作按平滑后的速度选择跑步档位，档位边界加入滞回，避免每帧来回混合。相同 tick 内较早的插值采样不再清空步态时钟；起跳、刹停和转身的动作选择保留。

Java 21 / `assemble` 编译打包通过，包内类与资源清单另行核对。沿用 RC25 的 204 个私有动作/配套文件，没有新增或更改原作派生数据；公开源码不包含这些文件。

按项目当前要求不运行自动测试、GameTest 或自动游戏操作。未做实际地形、水陆衔接、多人生存体验的游戏内验收，不将编译成功当作效果已确认。当前已打开的游戏仍是旧版；安装 RC26 需退出游戏、备份存档、移走旧 Blacklight JAR 后重新启动。客户端和服务端需同时更新。
