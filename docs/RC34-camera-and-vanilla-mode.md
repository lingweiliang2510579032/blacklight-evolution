# RC34：原版生存表现与解包追随镜头接入

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.34，网络协议 31。保留 Epic Fight 与 GeckoLib 前置。

## 未感染与普通模式

此前服务端 `PrototypeModeSystem.onPlayerTick` 在未感染时直接返回，没有将 Epic Fight 的默认/遗留战斗模式改回 VANILLA。另一个独立问题是 Epic Fight 的 `enableOriginalModel` 配置允许普通模式继续使用其骨架模型：只切换模式还不足以恢复 Minecraft 外观动作。

现在所有非黑光状态都同步至 VANILLA。Epic Fight 的模式事件拒绝非黑光玩家进入 EPICFIGHT，客户端在自动装备/按键切换产生视角和 HUD 副作用前拦截。模型选择通过 `VALIDATE_PLAYER_MODEL_TO_RENDER` 对非黑光玩家返回 false，走 Minecraft 原生玩家渲染；适用于本地和远端玩家。客户端恢复模式时保留当前 F5 选择，清除旧锁定；黑光第三人称镜头与黑光残留震动不作用于普通模式。移动动作事件在处理墙面和滑翔之前先校验模式。

以上同样适用于已感染后按 B 切回普通模式。黑光状态继续使用现有动作和能力。未修改用户的 Epic Fight 全局配置文件，不要求每次手动调整前置选项。

## 已接入与尚未接入

本轮接入分状态后方距离、距离变化率/减速区间、地形高度跟随过滤宽度。镜头采用居中后方构图，保留当前鼠标与锁定控制的旋转；**不是完整移植原版镜头引擎**。

距离切换的 0.15 秒指数混合、对高度历史的时间加权过滤、最多 0.6 方块的上下滞后限制是 Minecraft 适配算法，不是反编译得到的原作计算公式。水平移动和鼠标输入不加入位置滞后。墙体避让使用 Minecraft 的八条射线检测，遇障碍立即缩短镜头距离；另检测玩家眼睛与平滑跟随点之间的遮挡。传送、换维度、换玩家、切视角时清空历史。第一人称、正面第三人称、旁观、睡眠和使用物品瞄准时不覆盖其原有镜头。

原版俯仰、偏航的自动跟随求解、`changeRate` 的原作完整语义、锁定转向算法、吸收电影镜头轨道、FOV 曲线、特定攻击镜头和震屏没有在本轮完整移植。已导出相关字段供后续核对，没有用猜测值替换瞄准方向；既有 FOV/受击反馈仍为项目适配。

公开源码构建不含私有镜头配置，缺少该配置时保留前置镜头。本地 RC34 内置 214 份私有资料，其中此前 213 份与 RC33 逐文件一致，仅新增镜头配置。

## 验证与安装

执行 Java 21 编译、assemble 打包、Mixin 注册/目标签名静态核对及 JAR/ZIP 文件一致性检查。未运行自动测试、GameTest 或游戏内验收，未确认实际运行时 Mixin 应用或手感。

安装包 `Blacklight-Ascension-MC1.21.1-NeoForge-0.2.0-rc.34.zip`。退出游戏并备份存档后替换旧 JAR，客户端与服务端一起更新。试玩重点：未感染空手/持剑跑跳与挖掘；感染后进入黑光、再按 B 返回；第三人称跳跃/墙跑/锁定距离变化及贴墙避让。新世界和多人观察者表现仍需实际验证。
