# RC10：按身体部位区分吸收破坏

## 改动

移除整副受击方模型按统一平面切成两半的路径。现在由模型部位或蒙皮关节权重决定头、躯干、左右前肢/手臂、左右后肢/腿和尾部的归属，随后执行当前吸收场景的破坏方式。

- 普通小体型目标：头部压缩，躯干和四肢先保留，最后转换为生物质。
- 利爪、力量及猎手原版成对吸收：左右手臂/前肢分先后向外撕开，短暂保留组织连接丝，再回收身体。
- 利刃：依次分离手臂/前肢、腿/后肢和头部，部位有不同的翻转和下落，躯干不做统一腰斩。
- 铁锤：先压扁，各解剖部位进一步碎裂并向外散开。
- 鞭拳：分部位扭转、收紧，再回流吸收。

破坏从对应吸收动作的接触标记开始；最终缩小回收仍在结尾。RC9 的受击方骨骼动作继续播放，部位破坏叠加在其已摆好的姿势上。组织连接丝随撕开进度断开，碎块先缩小再进入主角身体。

## 模型覆盖与限制

普通模型通过 ModelPart 标注部位；本 Mod 的 Gecko 感染模型通过骨骼名称和父节点继承部位；Epic Fight 通过每个顶点的真实蒙皮权重切分关节边界。各纹理层共用部位中心，避免皮肤和衣物朝不同位置散开。只修改当前被吸收实体的渲染，不修改共享模型或真实碰撞箱。

这是 Minecraft 模型适配的破坏编排，不是恢复出的原版肢解事件或原版特效资源。源动作与破坏时刻仍需用户试玩对照。村民交叠双臂原本是一个模型部位，作为一个整体分离；无可识别部位的第三方模型保留整身生物质回收，不凭空假设其四肢位置。末影龙继续使用独立翼部/头部适配，不进入通用蒙皮管线。

仅编译打包，未运行自动测试或游戏内验收。请以实际试玩决定是否通过。
