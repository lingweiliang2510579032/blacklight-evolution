# RC49 战斗中抓取与吸收

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.49。

## 已确认的代码问题

旧代码仅在正式吸收阶段防止硬直、击退和受伤取消。伸手抓取、鞭拳牵引、攀附以及持有阶段受到任意正伤害都会取消会话。骷髅已经射出的箭即使在它被抓住后仍可命中玩家，导致抓取中途被取消。

普通生物还要求玩家的 onGround 为真；箭伤造成的短暂腾空会静默拒绝抓取。右键吸收仅在持有阶段接受，伸手尚未结束时的右键会丢失。

## 修正

- 成功认领目标后，从抓取到持有、吸收与投掷出手均保护玩家免受硬直和击退。普通伤害继续扣血，但不取消会话；玩家死亡仍释放目标，不发放吸收奖励。
- 被抓取目标在正式吸收前仍可受伤，但非致命伤不会取消抓取，也不会被外部击退拆散对位。正式吸收阶段沿用原有受害者保护，目标死亡或移除仍会清理会话。
- 受到伤害后短暂离地，脚下 0.65 格以内有方块碰撞支撑、竖直速度不超过 0.45 且未在流体中或飞行时，允许发起普通抓取。高空抓取规则没有放开。
- 抓取、牵引、攀附阶段新按下的右键会记录在当前会话中；抓稳后重新验证目标条件，再自动开始吸收。取消会话会同时丢弃预输入，不能套用到下一个目标。
- 当前攻击、蓄力、冲刺或爬墙阻止抓取，以及真正离地时，现在给出明确提示。另加武器会话检查，防止攻击和抓取同时控制动作。

不调整生命、伤害、抓取距离、锁定优先级或强敌削弱门槛。没有“进入战斗就不能抓取”的规则。

## 验证范围

沿用 RC48 全部 224 份私有动作和配套资源。本次只编译打包并静态核对资源、类和安装包，不运行自动测试、GameTest 或自动游戏操作。骷髅连续射击时的抓取与吸收连贯性仍待用户试玩确认。
