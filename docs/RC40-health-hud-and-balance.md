# RC40 左上角生命条与百点生命体系

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.40。

用户确认采用感染后生命 100 起步、敌我同步调整的方向。本版包含 RC37–39 的动作/F8、重生/抓取和镜头输入修复。

## HUD

感染后的角色使用左上角固定宽度的切角生命条：暗底、红色渐变、当前/最大生命数字、受伤后短暂保留的掉血轨迹。中毒/凋零有颜色提示，金色伤害吸收值单独显示。生命达到数百或数千也不会增加行数；原版心形层隐藏，护盾/装甲/感知提示移到下方。

HUD 按感染状态显示，因此退出黑光操作模式后仍能紧凑显示高血量。未感染、旁观状态及 F1 隐藏界面遵循对应的原版显示规则。实现为 Minecraft GUI 绘制，不是把原作截图贴到屏幕上。

## 数值

| 项目 | 本版 |
|---|---|
| 感染后基础生命 | 100 |
| 生命强化 I / II / III / IV | 150 / 225 / 325 / 450 |
| 四级生命强化生物质费用 | 200 / 400 / 650 / 900，逐级解锁 |
| 普通生物及 Mod 敌人生命 | 原值 ×5，包括已有存档中的生物 |
| 对上述生物或感染玩家的实际伤害、治疗 | 在护甲/抗性后按 ×5 的生命单位换算 |
| 黑光模式基础移动属性 | +8% |
| 基础 / 一级 / 二级疾跑上限倍率 | ×1.08 / ×1.25 / ×1.45，作用于 F8 配置值 |
| 生物基础移动属性 | +8%，静止敌人仍保持零速度 |
| 黑光模式攻击速度属性 | +15%；原生技能的动画速度另按下述方式处理 |
| 猎杀者连续攻击间隔 | 36 → 32 tick，攻击预警与命中帧保留 |
| 喷吐 / 重型 / 追猎变异体攻击间隔 | 65 / 45 / 34 → 58 / 40 / 30 tick |
| 战后再生 | 脱离伤害 8 秒后，每 5 秒回复 5 点生命 |
| 护盾 | 250 点独立耐久，按同一生命单位扣除伤害，保留重建时间 |

例：普通僵尸基础生命 20 → 100，猎杀者 48 → 240，重型变异体 80 → 400，蜂巢 160 → 800，监守者 500 → 2500。无护甲目标受到名义 9 点攻击时，对应扣除 45 点新生命。具体技能仍叠加各自升级、蓄力和减伤。

未感染玩家仍使用原来的 20 点基础生命和承伤单位；其攻击打到已换算的生物时相应换算，避免普通生存角色面对五倍血量却只造成旧单位伤害。玩家成长带来的额外生命不会反过来提高敌人伤害。

## 攻击节奏与一致性

原生武器技能不只读取 Minecraft 的攻击速度属性。地面普通连段缩短安全收招部分：已有源连段窗口最多压缩这段收招的 15%，回退窗口最多提前约一 tick；始终保留命中窗和受击间隔约束。没有整体加速源动画或跳过接触帧，蓄力、空中追击、砸地及吸收配对仍沿用原时钟。因此不能把“攻击速度属性 +15%”理解成所有动作播放速度统一 +15%。

护甲与抗性的原始伤害计算先完成，再换成新生命单位；不直接把五倍伤害送进护甲公式。护盾先按显示单位消耗自身耐久，溢出再换回原计算单位，避免之后重复放大。伤害吸收药水同时调整容量与获得量。

吸收资格继续按原始生命档位和当前生命百分比判断；普通小生物不会因为数值变大而突然要求先打残。吸收奖励不随生命单位凭空变成五倍。感染宿主转换先还原原始最大生命，避免转化时再乘一次倍率。

## 存档与交付

按修饰符 ID 安装或更新属性，旧存档按剩余生命比例迁移；死亡生物不会因此复活，反复加载也不会累乘。既有强化生命升级自动沿用第一级，新等级使用新增位，不覆盖旧进度。生命属性上限提高到至少 1,000,000，避免大型敌人被原版 1024 上限截断。

数值属性会保存到实体，回退到 RC39 及更早版本应恢复升级前存档备份；旧版没有本版的生命单位换算。没有直接改写用户当前存档或 F8 参数。

网络协议 **35**，客户端与服务器需要一起更新。私有动作/镜头资源仍为 222 份，与 RC39 相同。验证范围为 Java 编译、assemble、安装包类文件/资源/注册检查、Git 空白检查；未运行自动化游戏操作、GameTest 或自动化手感验收。实际战斗难度与 HUD 游戏内观感仍待试玩确认。
