# 上架渠道与商业化准备

项目：Blacklight: Ascension / 黑光：进化。作者：末者。调研日期：2026-10-01。

建议先准备免费 Java 公开版，以 GitHub 托管版本与源码、MC 百科承载中文玩法资料；网易版作为后续单独的适配和商业化项目。当前尚未公开上传本轮包。

## MC 百科与 GitHub

MC 百科适合玩家发现、教程、物品资料与下载入口。其收录规则要求有可运行且对外开放的版本，并排除侵权、必须付费获得本体或强制收费的模组；因此不能把本地私有包、空资源构建或纯付费版当作百科首发。先准备可公开运行的免费版，再提交条目。见 [MC 百科收录规则](https://bbs.mcmod.cn/forum.php?mod=viewthread&tid=3036)。

百科站内文件还需有作者授权或符合分发许可。作者可通过开发组入口申请文件管理权限。见 [MC 百科下载说明](https://www.mcmod.cn/download/35.html)。GitHub 负责保存对应版本源码、变更说明、可公开的 JAR 与校验值，不把它当付费商店。

## 网易《我的世界》

网易官方开发文档列出了电脑版 Java 模组、基岩版组件及手机版资源渠道，也提供付费组件和广告收益的机制。Java 资源不能直接投稿到手机版；电脑版需要确认目标版本，并关联已经在组件中心上架的前置。见 [作品管理](https://github.com/MCNeteaseDevs/netease-bedrock-wiki/blob/main/mcguide/35-%E4%B8%8A%E6%9E%B6%E4%B8%8E%E5%85%A5%E9%A9%BB/%E8%AF%BE%E7%A8%8B04-%E8%AE%A4%E8%AF%86%E4%BD%9C%E5%93%81%E7%AE%A1%E7%90%86%E6%A8%A1%E5%9D%97.md) 与 [投稿流程](https://github.com/MCNeteaseDevs/netease-bedrock-wiki/blob/main/mcguide/35-%E4%B8%8A%E6%9E%B6%E4%B8%8E%E5%85%A5%E9%A9%BB/%E8%AF%BE%E7%A8%8B05-%E6%AD%A3%E7%A1%AE%E4%B8%8A%E4%BC%A0%E4%BD%9C%E5%93%81%E7%9A%84%E6%96%B9%E5%BC%8F%E5%8F%8A%E9%80%94%E5%BE%84.md)。

这些公开教程标注的文档版本为 2023.3.9；不能拿其中的旧门槛、价格或结算周期当作 2026 年签约承诺。当前后台未登录核验，不承诺任何分成比例、审核时长或收益。

当前工程是 Minecraft Java 1.21.1 / NeoForge 21.1.244，并依赖 Epic Fight 和 GeckoLib。尚无证据确认网易投稿后台接受这套具体组合。电脑版需核验运行时和前置可用性；手机版需要将 Java 逻辑、Mixin、Epic Fight 动画与渲染等迁移到基岩版／网易接口，不是改 ZIP 名称就能上架。

进入网易阶段前，需准备：开发者身份与结算资料；确认素材商用范围；核对 GPL 代码及前置分发方式与平台条款；确认恐怖、伤口、分体等表现能否通过内容审核；提交真实安装包、图文和实际玩法视频。收益取决于下载／付费转化、平台条款与持续维护，不能按“上传即可赚钱”估算。当前保留用户认可的恐怖表现，不提前删改；如果渠道要求不同，单独确认适配范围。
