# RC4：大型吸收分武器与释放阶段

RC3 的两个具体问题：大型吸收统一播放 `CONSUME_LARGE`，仅替换右臂；普通吸收的手部接触约束贯穿全程。

## 大型目标

| 形态 | 动作来源与适配 |
| --- | --- |
| 普通 | 保留已接入的大型吸收动作 |
| 利爪 | 挤压头部的成对抓取动作，上身随动作变化 |
| 利刃 | 旋身切割的成对抓取动作，保留攀附支撑并限制根部转幅 |
| 锤拳 | 新接入 `headsmush` 成对动作 |
| 肌肉 | 新接入 `heart_to_head` 成对动作 |
| 鞭拳 | 新接入 `come_here` 成对动作 |

武器选择同时决定主角完整上身、双臂、接收方反应和播放时长。左手只在动作进入和结束时恢复攀附抓持，不再全程覆盖；腿部保持支撑。大型目标保留自身位置和站立支撑，避免被普通体型的抛掷轨迹拖走。普通模型和末影龙按武器区分反应与命中时点。

这些是原作抓取动作在 Minecraft 大型目标上的适配，不能称为原作中六套专属大型处决。当前本地检索只确认一组成对大型吸收动作；攀附腿部、反应幅度和事件时间仍是适配参数。

## 普通目标释放

抓持阶段按手部接触点对位；到各武器的释放时点后，目标改用自身解码出的 Motion_Root 位移，不再追随主角收手。锤拳在落地时结束水平位移并维持地面接触。配置缺失时也不再退回整段跟手。

释放时点是 Minecraft 适配标记，尚未恢复原作事件表。接触数据包含身体最低点，以减少头朝下时只检查双脚造成的入地。

本地配置 `consume-placement.data` 为 schema 3，网络协议 23。新加入 6 个私有动作文件，总计 191 个动作文件；不公开原作衍生资源。

仅编译打包。没有运行测试、GameTest 或游戏内验收；大型目标对位、武器节奏和释放轨迹等待用户试玩确认。
