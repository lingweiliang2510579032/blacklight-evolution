# R18 后玩法盘点与补全顺序

2026-09-20 根据当前源码核对。本文记录实际缺口和建议，不表示所列新玩法已经实现。旧 ROADMAP_ZH.md 和 KNOWN_ISSUES_AND_SLOTS_ZH.md 的早期“未完成”清单不能直接代表 R18 状态。

## 已有基础

- 原版/原型模式切换，利爪战斗、移动与升级框架。
- 普通生物与猎手的抓取、携带、吸收、投掷以及服务器奖励结算。
- 利爪、锤拳、刀臂、鞭拳模型和形态切换。R18 刀形态增加右刀臂刺入式抓取。
- U 菜单可购买移动、利爪和三个武器形态，Z 切换已解锁形态。
- 吸收可获得生命、生物质与 EP，玩家成长状态可保存。

## 已确认的玩法缺口

| 缺口 | 源码依据 | 玩家影响 |
| --- | --- | --- |
| 其他武器尚无独立常规战斗流程 | ClawCombatSystem.handle 在普通战斗请求前检查 canUseClaws；其他形态的接入集中在 PowerFormSystem 和 ConsumeSystem | 解锁模型、吸收动作不等于解锁一套完整可战斗武器 |
| 缺少普通生存获取病毒的入口 | ModItems 注册病毒样本与刷怪蛋；当前 data/blacklight 没有配方或箱子掉落配置，猎手掉落表为空 | 首次进入玩法仍依赖创造物品或调试操作 |
| 成长目标缺少分阶段引导 | UpgradeScreen 已有购买按钮，但没有新手目标或任务步骤 | 玩家需要外部说明才知道感染、切模式、削弱、抓取、吸收和升级的顺序 |
| 生物质的经济用途尚未接通这些购买流程 | BlacklightState.buy、buyClawUpgrade、buyMovementUpgrade 都扣 EP；spendBiomass 保留接口 | 吸收获得的两种资源缺少清晰分工，需先确定规则再调整平衡 |

## 建议制作顺序

1. **武器战斗**：每种形态分别定义轻击、重击、蓄力或特殊技、空中行为、命中范围、硬直和恢复；形态独立动画与服务端命中窗口同时交付。刀臂侧重劈砍，锤拳侧重砸地破防，鞭拳侧重中距离控制，利爪侧重快速近战。具体数值和技能列表尚未确定。
2. **成长与生存流程**：确定病毒的生存获取途径，增加游戏内阶段目标，串联首次感染、首次吸收、第一次升级；明确 EP 与生物质分工，保留已学技能释放不扣生物质的既有规则。
3. **战斗对象与世界内容**：感染体遭遇、敌人攻击预警、不同敌人价值、局部感染事件，再扩展据点与警戒。不要以无限刷普通动物作为主要成长手段。
4. **长期目标**：伪装、追捕、进阶感染体、Boss、任务与记忆内容；分别立项，避免一次性加入空壳系统。

## 第一批武器玩法的验收目标

- 每种已出售形态至少有一套能实际命中、产生明确差异的基础战斗动作。
- 按键提示与当前形态一致，不把所有输入导回利爪。
- 命中距离与模型轨迹相符；墙后目标、重复命中、切形态取消和抓取状态冲突由服务端处理。
- 已完成的抓取吸收、原版模式和旧存档解锁不回退。
- 自动化验证后提供真实游戏试玩；动画效果仍需玩家实际验收。
