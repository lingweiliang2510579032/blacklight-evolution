# Blacklight: Ascension：基础能力与军事科技方向

状态：以下表格保留 RC28 核对基线；RC29 基础能力进展见 [原版依据与边界](RC29-utility-source.md)。军事科技、实验室、超级士兵尚未实现。2026-09-26。
用户确定：两条都要，先突袭夺取技术，再建立自己的实验室。最新补充要求是优先关注盾牌、装甲与感染视觉等基础能力。

## 基础能力现状与第一阶段要求

| 能力 | RC28 代码现状 | 补全要求 |
| --- | --- | --- |
| 护盾 | 防御页可解锁和切换；正面夹角判定减伤 80%，触发后恢复 40 tick；左手独立模型 | 清晰的展开、受击和恢复反馈；界面显示是否可格挡；核对身体朝向与实际防御方向一致；处理武器、抓取与盾牌的视觉遮挡 |
| 装甲 | +12 护甲、+4 韧性、+0.6 击退抗性，移动速度降低 25%，禁用滑翔；已有头、躯干和腿部外壳 | 补全整体覆盖和变身过渡；显示当前状态与移动代价；核对停用、死亡、重进和退出黑光模式时的属性清理 |
| 感染视觉 | 32 格内感染实体线框，最多显示最近 48 个已同步实体 | 用清楚的目标表现区分感染体和普通生物，提供开启状态及范围反馈；不以调试包围盒作为最终视觉；保留多人目标信息边界 |
| 热能视觉 | 24 格内存活实体线框 | 与感染视觉有清晰且有用的差异；说明哪些目标可探测；低亮度环境可读性和关闭后的视觉恢复 |
| 入口 | U 升级菜单内有防御/感知项目，Z 轮盘按 Tab 切第二页；同组互斥，可与武器共存 | 防御/感知入口明确可见；显示启用、停用和冷却，停用提示不能仍说已选择形态 |

以上是静态源码核对，不代表游戏内外观、联机同步和手感已验收。保留当前项目不运行自动测试/GameTest 的工作约定。

## 生存核心循环

发现军事设施线索 → 潜入或突袭 → 取得研究资料、军用部件和电源 → 建立生物实验室 → 分析样本、解锁并制作设备 → 利用设备挑战更严密的设施和强化敌人。

现有冰下研究站保留为病毒起源线索。新路线应能通过设施、战利品和后续情报推进，不把村民交易升级设置为全程唯一入口。普通材料可用于基础建筑和机器外壳，但核心技术来自设施与样本研究。

## 第一批有用途的物品与设备

| 内容 | 来源与用途 |
| --- | --- |
| 加密研究资料 | 设施终端或军方任务目标；在实验室解析具体项目，不直接兑换普通 EP |
| 军用电源模块 | 军方仓储与设施拆解；承担设备供能和行动补给 |
| 精密电子组件 | 军用设备回收；制作、维修检测设备和实验仪器 |
| 生物样本容器 | 收集感染体材料用于分析；不把尸体材料简单等同于进化点 |
| 生物分析台 | 安放在玩家实验室，处理样本与资料，展示输入、产物、耗能和已解锁项目 |
| 感染检测仪 | 人类阶段也能识别感染威胁；与主角感染视觉共享感染分类，但具有自身操作、范围和供能限制 |
| 抑制装备 | 针对特定强化生物提供有限时间的交战窗口；效果、免疫与消耗在制作前明确展示 |
| 设施访问凭证 | 提供潜入或接近任务目标的路线；不把普通方块门禁当成无法绕过的绝对保护 |

这些是拟议的 Minecraft 生存适配，不宣称以上合成、耗能、研究规则来自原作。

## 军方与超级士兵

先形成军方阵营、设施驻防和警戒，再接强化敌人。超级士兵需要独立模型、动作和近战行为：可读的起手、格挡或反击、扑击/擒拿、可利用的恢复窗口，并与玩家抓取和吸收规则衔接。不能用普通僵尸加血量冒充完成。

已确认本地私人资料存在 SuperSoldier.p3d、骨架文件与 SuperSoldier-animations.json（62 条索引），包括格挡、反击、搜索、无线电和抓取相关动作。索引存在只证明有制作依据，不表示模型、动作、AI 和完整战斗条件已接入；需分别核对、解码及重定向。原作派生资料和含这些资料的包继续只用于本地私人交付。

## 落地顺序与完成边界

1. 先补防御/感知的入口、真实效果、模型反馈和开启/关闭生命周期。
2. 军方设施和首批战利品接入真实世界获取，保留旧档进入新生成区域的路径。
3. 实验室接通资料解析、研究解锁、耗能和设备制作，形成从突袭到研究再回到行动的完整流程。
4. 超级士兵作为强化交战目标；模型、动作与 AI 各自列明完成程度，不因有刷怪蛋就标记完成。
5. 更大军事基地、追捕、载具与城市作为后续扩展，不混入第一批交付承诺。

以后构建 JAR 与 ZIP 继续遵循已落实的命名格式：Blacklight-Ascension-MC<我的世界版本>-NeoForge-<Mod版本>。
