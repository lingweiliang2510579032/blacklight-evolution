# Prototype 动作后续还原清单

研究目标为 2009 年《Prototype》Alex Mercer。当前基础连招机制已修复；R22 地刺试作失败并回退。下列事项均不是完成声明。

本清单只记录工作和验收要求。原始游戏文件、抽取动画/骨骼数据、私人安装目录、解码元数据及含这些信息的中间文件留在本地分析区，不写入此清单、公开仓库或 Mod 安装包。

## 参考先验证

- [ ] 将已定位的动作资源逐项对应到实机可观察招式；分开一代与二代，不从文件名推断连击段数。
- [ ] 核对时长、采样率、绑定姿态、正面方向、左右手、坐标尺度和根运动；用完整起手至收势验证解码结果。
- [ ] 每招保留可追溯的参考编号及实际观察时间点。公开文档只记观察结果和可公开来源，不记录本地私有路径或抽取数组。
- [ ] 标注脚掌支撑、重心转移、髋/胸先后、肩肘轨迹、双端刀刃轨迹、接触和收势，而不是只比较手臂位置。

## 独立制作与接招

- [ ] 在同一时间线制作完整连段；尚未验证的段数、顺序和时长不写死为原版事实。
- [ ] 髋、胸、肩、肘独立控制，腕 IK 绑定有效肘部 pole，明确前臂轴向 roll 和武器朝向。
- [ ] 所有转身在足部 IK 求解前完成；支撑足世界位置固定，摆动足有抬起、落下和再次承重过程。
- [ ] 根位移与关节动画从同一场景、同一时钟导出；不在导出后给全身补旋转，也不另用通用推进曲线替换已制作的脚步。
- [ ] 在已完成伤害接触的收势点拆分连招；下一片入口对应上一片出口，未接招时才走完整回待机。
- [ ] 两端刀刃、爪、锤拳和鞭的接触方式分别处理，不把同一挥臂曲线放大后用于所有形态。

## 运行时验收

- [ ] 使用最终导出产物重新加载，检查头、胸、非攻击臂、武器与地面的相交情况；双端刀检查两端。
- [ ] 记录支撑足世界漂移、连招交界处位置/速度变化及命中窗口；几何距离和逻辑测试不能替代画面判断。
- [ ] 原地、向前移动和受阻环境分别验证。地刺需完整展示手部入地、维持和退出地面。
- [ ] 真实客户端从侧面和前方三分之四连续捕捉，完整显示脚底和举手范围；漏帧必须记录并补录，不能压缩时间后冒充逐帧对照。
- [ ] 验证每次实际攻击仅产生一次动画开始，没有中间待机、重复播放或旧请求覆盖新连段；同时检查第一人称玩家和其他观察者。
- [ ] 验证实际武器接触与服务端伤害时刻相符，取消和恢复不残留队列，受伤抗性不会把下一击变成差额伤害。

## 替换与交付

- [ ] 一招通过完整对照后再替换生产资源；失败试作留在本地草稿，保留可验证的回退版本。
- [ ] 对交付状态区分“机制修复”“动作适配”“已按参考核对”“仍待重做”，不把测试通过写成原版还原通过。
- [ ] 公开构建只包含本项目可发布的代码和素材；检查研究中间文件及私有路径未混入 JAR、源码或文档。
