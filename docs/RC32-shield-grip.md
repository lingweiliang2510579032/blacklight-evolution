# RC32：护盾握持和疾跑朝向修复

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.32。网络协议 29，两端一起更新。

RC31 的护盾在疾跑时横到肩颈附近。此前以肘部 Hand_L 为原点，再抵消手腕静态偏移，中心位置错误；更关键的是只重定向了身体与 Wrist_L，遗漏了原版 L_Wrist_Grapple 的独立旋转、平移轨道。

## 修复

- 将模型直接绑定 Tool_L 手腕，移除旧版肘部加抵消腕部偏移的变换。
- 按本地原版护盾的方向重新校准方块几何；方块数量、造型、破损档位保持。
- 在四份护盾动作中补出手腕空间的 L_Wrist_Grapple 轨道，运行时与身体选择同一片段、时间和混合权重；相邻采样使用平移/缩放插值及四元数插值。
- 展开片段没有单独的挂点通道时按来源静态关系计算；跑步、疾跑、受击使用各自的原始挂点变化。
- 重建组织和碎片同步使用新的模型坐标，避免更换绑定后脱离盾面。

## 验证和边界

编译打包、私有资料完整性和方块法线检查；用实际导出的身体、挂点和模型数据做离线站立、跑步、疾跑及受击姿态预览。不运行自动测试、GameTest 或自动游戏验收。实际所有动作的穿插及混合衔接仍需试玩。

私有资料仍为 213 份，四份护盾 JSON 新增挂点字段，其余 209 份与 RC31 一致；身体 animation 字段不变。原始轨道仅进入本地私有包，不公开提交。盾面尺寸、中心偏移与方块形状是 Minecraft 适配，不宣称原样移植模型。

安装 `Blacklight-Ascension-MC1.21.1-NeoForge-0.2.0-rc.32.zip` 中的 JAR 替换旧版，并重新启动。保留当前前置依赖。当前运行的 RC31 不会自动变成 RC32。
