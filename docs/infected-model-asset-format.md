# 感染模型资源格式

`assets/blacklight/infected_models/` 收录 82 个原版物种：已确认的 80 个普通物种稿，其中监守者和铁傀儡改用巨构稿，并加入末影龙、凋灵。全库为原创可编辑模型导出的实际网格，不是预览图片。

四个巨构模型保持确认尺寸：监守者高 36 格、铁傀儡高 30 格、凋灵高 40 格，末影龙翼展 112 格。普通模型使用各物种的成年参考比例；动态幼年/史莱姆大小等由运行时代码处理。专属 Boss 战斗动作不属于这批资产。

## 重新导入

标准库 Python 即可运行，不需要 Blender、Pillow 或下载依赖：

```text
python tools/import_infected_models.py --ordinary <infected-all-species目录> --bosses <infected-bosses-v1目录>
```

默认导入到项目的 `src/main/resources/assets/blacklight/infected_models/`。可用 `--output` 指定其他资源目录。输入是原模型包中的 `*-geometry.json`、`materials.mtl`、普通模型 `coverage.json`、Boss `manifest.json`。源可编辑模型不被修改。

导入会检查四个 Boss 是否齐全、面和材质数是否匹配、坐标是否有限、Boss 是否有未绑定部件以及骨架是否有缺失父节点/循环，并要求合并后恰好覆盖 82 个物种。清单保存每个源几何文件的 SHA-256，供追溯确认稿。

## JSON 约定

- `manifest.json` 的 `models` 数组含 `id`、资源 `file`、`boss`、骨骼和三角形计数、两个包围盒、`referenceScale` 与源摘要。
- 每个物种文件含 `species`、`boss`、`bounds`、`baseBounds`、`referenceScale`、`bones`。
- 坐标为格，Y 向上，模型面朝 -Z。所有顶点与枢轴是模型的绝对静止坐标。导出时统一减去整个模型最低 Y，让 `bounds.min[1]` 为 0。渲染端不要再重复落地偏移。
- 每个 bone 为 `name`、`parent`、`pivot`、`vertices`、`triangles`。`vertices` 是平铺的 `x,y,z` 数组。`triangles` 每四项是 `i0,i1,i2,rgb`，RGB 为无 alpha 的 24 位整数。顶点索引仅限当前骨骼。
- 导入将原模型像素坐标 `(x,深度,高度)` 转成 `(x,高度,深度)/16`；交换轴会改变手性，所以三角形绕序已反转一次。渲染端无需再次反转。
- 颜色直接来自 MTL 的 Kd，并非 Blender 预览提亮后的颜色；运行时仅需白色纹理与逐面 RGB。法线可在资源加载时按三角形一次计算，不必每帧重复。
- 父节点必定排在子节点前。父级变换与当前骨骼的 `T(pivot) R T(-pivot)` 相乘，顶点保持绝对静止坐标，不再加父级静止位置。
- 部分骨骼无三角形，作为子节点的枢轴存在；不可因空几何而删除。

## 比例和普通动作骨架

`bounds` 包括翅膀、触手、感染骨刺；`baseBounds` 仅统计结构底模参考部件。两者均不是完整的实体碰撞箱定义，不能统一用高度强制套入原版碰撞箱。例如旋风人的底模只有头部，蜘蛛底模不包含后加的节肢，恶魂的触手位于方块身体外。

`referenceScale` 修正共用细节预览比例的物种，例如巨人 6 倍、洞穴蜘蛛 0.5 倍、远古守卫者 2.35 倍、恶魂 4 倍。几个小型飞行生物、鱼、坐骑按原版成年参考体型缩放；感染突起仍允许超过身体体积。Boss 已在资源中做成巨构尺寸，参考缩放为 1。

普通骨架以 `root -> body` 开始，头、腿、翅膀等连接到 body；有颈部时头连接 neck；龟的鳍足连接对应前后腿；蠹虫、末影螨的足连接对应腹节。左右以资源坐标 X 正负表示。原僵尸稿的大小写骨骼别名已合并到相应身体部件，防止感染层和身体分离。

四足是 `front_-1/front_1/hind_-1/hind_1`；人形为 `arm_-1/arm_1/leg_-1/leg_1`；翼为 `wing_-1/wing_1`；蜘蛛足为 `leg_<侧>_<序号>`；鱿鱼触腕为 `arm_0..7`；恶魂触手为 `tentacle_0..8`。Boss 保留模型包里的实际关节层级，为后续专属动作提供绑定位置。

资源导入后的几何检查：82 个模型、117858 个非退化三角形，约 3.95 MB JSON。这里只说明资源格式与几何检查，不代表游戏内观感或战斗已验收。
