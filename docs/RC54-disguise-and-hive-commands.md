# RC54：伪装识别、巨巢指令与感染表现

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.54。

## 已确认的原因

RC53 游戏日志记录第一次 `/locate structure blacklight:colossal_hive` 耗时 112995 毫秒，主线程落后 2260 tick。最终返回坐标 `-19872, -19744`，不是指令未注册。两次 `/place structure` 返回“放置结构失败”。原生命令会同步寻找大量候选，并把同一套自然选址条件用于手动放置。

RC50 的 `reveal` 同时恢复本体并无条件增加 60 警戒。普通攻击尚未结算、所有弹射物生成（包括浮漂）、能力选择等都会调用它；警戒大于 25 又禁止伪装。这把外形、目击和追踪混在了一起。

## 伪装与警戒

修复以原作“外形切换与身份曝光分开”的规则为依据。普通工具操作、空挥、取消的攻击不自动恢复本体；真实敌对行为由受害者及有视线的相关敌人判断。可见生物武器和防御能力展开仍恢复本体，无人目击不凭空报警。感染视角、热能视角及关闭能力不应直接破坏伪装。

本体和最近吸收身份分别记录曝光。隐蔽换到未曝光身份可以脱离相关敌人的追踪；换回同一个已曝光身份不能立即洗掉仇恨。新吸收身份有新的身份代数，旧箭的延迟命中不会破坏后来换上的新身份。曝光保存于服务端玩家数据，死亡清理追捕状态。

依据：[Prototype 官方 Prima 攻略](https://www.scribd.com/document/339963628/Prototype-Official-Prima-Guide)（2009，第 6–9、35 页）区分敌人视线、身份与警戒，并说明使用能力恢复 Alex 外形；[Steam 官方手册](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/10150/manuals/Manual_english.pdf)确认身份切换与伪装动作菜单。本地解包动作不能证明原作整套警戒逻辑，视距、视角、警戒衰减及 Minecraft 阵营仍是本 Mod 的适配值。

## 巨巢入口

```mcfunction
/blacklight hive locate
/blacklight hive place
/blacklight hive status
/blacklight hive cancel
```

需要管理员权限。定位只返回位置，不自动传送；默认半径 32768 格，可追加半径，范围 1024～65536。搜索区分已经存在的自然结构、加载中的人工巨巢和未加载核实的生成候选，不把候选冒充建好的蜂巢。搜索最多 180 秒，可随时查看状态或取消。

放置会改造当前位置周围 113×113 格的地形，要求完整区域已加载、连续干地、高差不超过 12 格。先检查结构、流体、方块实体及非地形方块，通过后才逐列建造，每 tick 最多 32 列，列间检查 5 毫秒预算，总时限 240 秒。预检通过后先完成布局中的入口平台，将仍在建造范围内的执行者移至入口，避免超平坦抬高地基把人埋住。其他玩家占据待填位置会停止建造。完成整座结构后才生成居民。

取消建造、退出游戏或卸载相关区块不会回滚已完成的部分，聊天会说明保留的范围。不强制加载区块。不要在自己的建筑中执行放置。原生 `/locate`、`/place` 仍使用 Minecraft 自己的同步执行机制，试玩建议使用上述新入口。

原生命令仍然存在。默认超平坦此前是地下基础越过世界底部导致失败；现在会抬高地基，仍校验上方世界高度。自然选址先筛选中心生物群系和高度，再检查周围地形，减少无效高度计算。

## 蜂巢与吞噬

蜂巢核心负责生成守卫，巢生吞噬者是另一只会进食成长的感染铁傀儡。此前核心波次只有潜伏者、喷吐者与重型变异体，遗漏了猎手；现在每波包含猎手，并在附近干燥、可站立且无碰撞的位置寻找出生点。仍是有限波次，不无限刷怪。旧存档已经刷完旧波次、从未生成猎手的核心可补一波单只猎手，状态随存档保存。

吞噬者的 80 tick 进食过程增加六股立体触手：伸出、缠绕实际目标身体、收紧，并将组织向胸腔回流。感染体与普通原版猎物在末段一同收缩，成功吸收后隐藏尸体，保留正常死亡结算，避免目标解绑后弹回完整模型。触手的位置和阶段使用服务端同步的目标与进食时钟，随吞噬者成长缩放；中断、目标卸载或进食结束后清除。触手为 Minecraft 中自制效果，并非原作资源移植。

## 普通感染体回归原生物模型

此前 78 类普通感染体优先使用整只自制网格，会完全跳过原版身体和贴图。现在普通感染体使用对应生物的原生渲染器、模型骨架和皮肤变种，保留牛角、猪鼻、羊毛、蜘蛛腿、鱼鳍等辨识特征；巨构四类及其成长形态继续使用既有专属网格和多段判定。

变异叠加在实际摆动的部位上：按身体结构选择不对称组织和骨质增生，并在头侧、躯干侧及一侧腿部切出阶梯形啃食凹口，露出内层组织和碎骨。凹口保留周围原贴图 UV，不改动共享模型；薄翼和鱼鳍不强行挖穿。羊毛外层同步切口，避免覆盖身体损伤。整体染色减轻，不再把物种本身的颜色完全压暗。

这次是原生模型基础上的程序化变异，并不表示已经为全部生物逐只雕刻了独立新模型，也不包含新的巨构战斗连招。实际外观仍待用户试玩判断。
