# RC11：吸收特效位置和身体重叠修正

针对 RC10 试玩截图中的空心红描边、悬空碎块、红色药水圈和身体重叠。

- 吸收过程中关闭 Epic Fight 目标引导描边，保留相机锁定与抓取目标；抓取和普通战斗的描边不受影响。
- 吸收束和短时碎屑改由实际绘制的受击方网格部位中心产生，共用骨骼姿势、模型变换、肢体分离和回收后的坐标。停止在站立高度生成整圈独立特效。
- 缩短碎屑寿命，加入向外运动和下落，减少碎屑数量和体积，避免碎块保持悬空环状。回收束在后段形成，减少细线数量并增加组织束粗细。
- 防重叠改为根据受击方当前旋转姿势计算躯干在分离方向及垂直方向的投影尺寸。横躺的生物不再只使用站立宽度和固定高度阈值。服务端和客户端使用同一求解方法。
- 关闭黑光感染的原版药水粒子显示，迁移旧存档现有感染状态的粒子标志，保留感染、时长和等级，不修改其他药水效果。

仅编译打包并按用户要求启动供试玩；没有执行自动测试或游戏内验收。接触位置和观感仍需用户确认。
