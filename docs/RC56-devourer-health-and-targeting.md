# RC56：成长生命条与巨构锁定

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.2.0-rc.56。

## 成长状态与生命条

巢生吞噬者从培育阶段开始显示生命条，其他进入进化的巨构宿主也显示。条内比例始终是当前生命 / 最大生命；标题标明培育、畸变、孵化、苏醒、衰退或巨构完成，不用成长进度冒充生命值。

玩家已经在附近时，形态变化会立即更新血条订阅，无需离开再回来。死亡、卸载和停止追踪时清理订阅。绑定末地战斗的龙继续使用原生末影龙血条。

体型接近最终大小不代表完成进化。成长仍需足够生物质、有效核心、营养节点、感染密度和空间。完成前摧毁核心会导致成长衰退。本轮没有更改这些门槛、生命或伤害数值，也不修改旧存档的成长数据。

## 巨型生物锁定

修复 Epic Fight 将实际命中的身体部位解析为父实体后，又因父实体不可直接命中而拒绝锁定的问题。锁定仍发送唯一的父实体 ID，伤害仍通过真实身体分段结算。

巨体的锁定距离、遮挡、目标切换和镜头构图改为检查实际可见身体部位。可见部位必须同时处于锁定距离内；贴近外侧肢体时，不再因为躯干根部较远而误判超距。显式锁定的优先级保持不变。

## 验证范围

本轮执行源码审查、编译和打包检查，不运行自动化测试或 GameTest。游戏内的锁定手感和生命条表现仍需试玩确认。
