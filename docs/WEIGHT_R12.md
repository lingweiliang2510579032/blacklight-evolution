# R12 抓取与吸收的发力节奏

针对试玩反馈“动作僵硬、缺少力度和节奏”，重做九段原创动画：近身抓取、持续持有、投掷、鞭拳抓取，以及徒手、利爪、锤拳、刀刃和鞭拳吸收。

- 所有吸收起手接续持有姿势，修复先放下双手再执行的断档。
- 蓄力时先转身、压低重心，再挥臂；主要发力段集中在 0.08–0.10 秒内。
- 接触姿势保留 0.08–0.10 秒，随后回弹、收拢与恢复。只调整角色关键帧，不暂停世界或服务器。
- 被抓生物在接触前抵抗，接触后停顿、回弹和蜷缩；玩家、受击姿势和撞击音共用对应形态的接触时刻。
- 锤拳目标在下砸前保持抬起，接触时落地；修复蓄力前就开始下沉的问题。
- 保持既有动作总时长、按键、奖励和取消条件；其他攻击连段及跑酷不在此次改动范围。

## 创作与验证

`tools/author_weight_r12.py` 使用本地 Blender IK 工程制作、烘焙；需按 `ASSET_WORKFLOW.md` 准备参考骨架。先前脚本不会自动带入 R12，重建时应最后执行此脚本。

```text
blender -b --python tools/author_weight_r12.py -- <本地参考目录> <R7 工程目录> <输出目录>
gradlew test build runGameTestServer -PwallTraversalTest
```

新增回归检查覆盖持有与吸收首帧连续、锤拳短促下砸及接触停顿、目标在蓄力阶段不提前下降。沿用逐帧武器与头部间距检查，以及七个独立存档录制场景。

这一版是动作力度的迭代，尚不能称为逐帧还原《虐杀原形》。接触时间是本 Mod 的原创调校值。网上的形态说明可用于核对动作类别（[Consume 资料页](https://prototype.fandom.com/wiki/Consume)），不能代替原作视频逐帧测量或玩家手感验收。
