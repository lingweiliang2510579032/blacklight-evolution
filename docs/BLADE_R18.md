# R18 刀臂朝向与刺入式抓取

按用户确认的双端刀臂设计保留一体相连的上下刀刃，将刀面从前外侧转向前臂后外侧。几何挂载角从 30° 调整到 -45°，上下刃仍属于同一连续网格。

刀形态使用独立的右臂抓取、悬提、吸收与甩出动画。抓取先由角色迈近、收肩，再向前刺入并挑起目标；目标在前 5 tick 不会被提前拖动。20 tick 后进入等待玩家选择的持有状态。右键吸收仍需玩家再次输入，不会自动触发。

持有及吸收以右刀刃内部接触点为约束，左右转头及俯仰时跟随视角，依据生物身高调整悬提位置。右臂 IK 将实际刀身对齐目标躯干；生物绕刺入点挣扎。吸收期间沿刀臂略微拉近，取消此前通用逻辑中的向地面下落。甩出在第 6 tick 放开，释放动画向外翻腕，避开头部。

## 验证

- 89 项单元测试：动画时长、四元数、持有/吸收首帧衔接、刀刃接触点与逐帧头部间距。
- 25 项游戏服务器测试：增加刀形态普通生物抓取、视角跟随、吸收不下落、甩出不发奖励。
- 真实客户端：猎手吸收；鸡、幼年鸡、猪、村民和旋转视角下的抓取接触；刀臂甩出。
- 两端刀刃的 1478 个三角面通过完整公共边连通。最终构建核对资源与源文件一致，排除测试类。

以上覆盖本次改动的抓取/吸收链和测试生物，不代表所有第三方生物骨架及所有战斗动作都已逐一验证。

## 编辑入口

- `tools/build_blade_r17.py`：当前 R18 网格生成器，保留已认可的 R17 造型轮廓。
- `tools/author_blade_r18.py`：右刀臂专用动画关键姿态与甩出翻腕。
- `GrabPlacement` / `GrabHoldPose`：服务端身体位置和客户端实际刃部接触约束。
- `ConsumeSystem` / `ConsumeVictimPose`：阶段衔接、奖励与生物受力姿态。
