# Forge 1.20.1 dev.4 技能同步

目标分支 `forge-1.20.1`，Java 17、Forge 47.4.10、GeckoLib 4.8.4。
对应 NeoForge PR #16，跨版本跟踪 #15。按用户要求并行提交；来源还未合并，当前适配基于来源开发提交 ced6197，不能把它称为已合入 SHA。

## 功能及平台适配

同步临界质量、地面/空中毁灭技、身体恢复、方块地刺、组织束、镜头反馈和子弹俯冲高度分层。≤50 格红簇，>50 格追加红雾；服务器按真实落差增强伤害、破坏能量和坑深，使用保护事件及原生掉落。
同步按住空格原地蓄力清除行走和水平惯性，以及连续姿态时钟修复。

保留 Forge capability 与 SimpleChannel，升级协议 forge-1.20.1-2。登陆/追踪完整状态快照增加后上限由 20 调到 32，仍保留包大小、重复字段和解码检查。
Forge 1.20.1 原生伤害先消耗金色吸收生命，再经所有 LivingDamageEvent 决策后扣临界储备和红血。伤害取消不能提前花掉储备。死亡克隆显式恢复旧 capability 来保留冷却历史。
静态 GPU 三角面通过 1.20.1 BufferBuilder 上传，复用顶点缓冲；雾函数及顶点属性顺序按该版本适配。第三人称实体 PoseStack 带世界视图变换；保存当前帧世界视图的逆矩阵，还原 FX 身体/手腕起点，包含视角事件的额外旋转，不能仅用 Camera.rotation() 猜测。重载监听使用 Mod 事件总线。

## 安装包

完整技能交付为 external-profile（251 个运行资料）；默认公开 bundled（224 个基础资料）不能冒充新技能完整版。外部身体动作仍在仓库外，原创模型和导出工具随 PR 提交；原始 FX 研究数据、原游戏网格纹理和 QA 类不进入安装 JAR。
必须分发经过 reobfJarJar 的完整 JAR，包含 MixinExtras；不能使用 slim 中间文件。两端使用同一版本、资料和依赖。
