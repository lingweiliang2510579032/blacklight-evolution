# RC48 肌肉、徒手与利爪对位

## 肌肉与徒手

- 肌肉 `alex_grap_muscle_arm_rip_rcv`：本地 FIG 的两条 spawnGib 分别引用 `R_Wrist_Grapple` 和 `Motion_Root`，约 0.833333 秒生成；effectConsume 从 0.8 秒开始。本版分离右臂/对应右前肢，头、另一侧肢体和双腿保留在剩余身体上，再分别回收。修正旧逻辑同时拆两只手臂、其他部位也散开的表现。接收者按 FIG 的 0–30 帧播放后保持。
- 徒手 `alex_grap_punch_chest_rcv`：effectConsume 从 0.666667 秒开始，目标节点为 `Spine_2`。本版改为胸口受击和胸部中心吸收，移除默认压头形变。接收者按 0–90 帧播放后保持，玩家余下收尾继续交还原有移动机制。
- 分离轨迹、方块模型压缩、回收时长属于 Minecraft 适配；没有导入原版碎块模型。原版肌肉、徒手其他处决变体仍未接入轮换。

## 利爪在身后/双方错位

RC47 试玩日志确认当时对象为苦力怕，受害者动画已应用；截图仍显示手部与生物脱离。本版处理发现的三个缺口：

1. 利爪网格之前只在移动类动画中读取 Tool 手腕旋转。抓取、吸收和收尾阶段现在也使用该旋转，掌部与尖爪跟随手腕，前臂仍连在肘部。
2. 压头时不再固定使用第一帧的双方偏移；握持期间按当前手位和当前受害者接触点求位置，释放后再继续受害者自己的位移。主角被地形挡住时，客户端和服务端都将实际位置误差传递给握持目标；仍保留碰撞与视线检查。
3. 利爪压头期间增加双手接触修正，目标是经过身体动画和渲染插值后的头部位置。只修正握持阶段的手臂，进入释放时淡出；大型攀附和其他武器不套用这项修正。

这些代码修正尚不能证明截图中的所有错位已经消失，需要用户在苦力怕、动物和贴墙位置试玩确认。

## 构建

本地 profile 为 `rc48-motions`，仍有 224 文件。相对 RC47 修改肌肉/徒手接收者片段、对应接触投影与事件资料四份文件，其他 220 份原样保留。动画秒数改从实际片段末帧读取，避免用向上取整的 tick 长度拉伸动作。

只编译、打包并核对包内容；未运行自动测试、GameTest 或游戏内自动验收。正在运行的 RC47 不自动关闭。
