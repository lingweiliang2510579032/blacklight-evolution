# 0.2.0-rc.1 用户试玩清单

全部为待验收，没有自动勾选。按用户要求不由代理运行。先备份存档；每条记录形态、按键、目标、距离、实际结果即可。

## 先验关键操作

- [ ] B 双模式切换后，原版挖掘、物品使用和背包能恢复；黑光模式不会串键。
- [ ] Z 切换形态，U 小窗口/大 GUI 缩放下文字清晰、能滚到底、购买前置正确。
- [ ] 普通地面左右键不会跑向远处目标，也不会离开很远仍伤到原地目标。
- [ ] 普通、利爪、刀臂、锤拳、鞭拳逐一体验地面连击、空中左右键、蓄力和组合技，记录具体失效招式。
- [ ] 移动生物可以实际命中；空中追击随目标更新，墙后目标不隔墙受伤；无目标飞踢有前进位移。
- [ ] 锤击特效出现在实际接触位置；落地和墙面反馈不残留、不删除建筑方块。
- [ ] 鞭拳在 12 格以内无遮挡可抓，超出范围不能抓；抓住后跑动、转向、投掷和吸收目标随动。
- [ ] 最大生命 20 的名单内生物满血可抓；最大生命 50 时 7.5 可抓、超过 7.5 不可；100 时门槛 15；150 时门槛 22.5；500 时门槛 75。
- [ ] 被动动物如果最大生命被强化到 50 及以上，也按 15% 处理；已驯服宠物不被误抓。
- [ ] 受伤中断、目标死亡、退出重进后，玩家动作/移动和生物 AI 正常恢复，没有重复奖励。
- [ ] 墙跑看到正确背部方向、头部不穿墙；沿墙跳和脱墙后正常落地，无闪退。
- [ ] 从生存获取病毒到吸收、升级、蜂巢战斗与奖励能持续游玩，退出重进后成长不丢失。
