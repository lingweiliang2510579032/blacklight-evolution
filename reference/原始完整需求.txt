# 《我的世界》虐杀原形 Mod —— 完美复刻原版 完整需求提示词


## 一、项目概述

### 1.1 项目定位

基于《我的世界》Java版，**100%忠实复刻**《虐杀原形》（Prototype）原版游戏的核心体验。玩家扮演**Alex Mercer**——一个由**黑光病毒（Blacklight Virus）**集合而成的“原型体”（Prototype），拥有随意改变自身形态的能力。Mod 的目标是将原版中所有**攻击能力、防御能力、感知能力、移动能力、吞噬与伪装机制**完整还原到 Minecraft 世界中。

### 1.2 目标版本与加载器

- **游戏版本**：1.20.1 或 1.21
- **模组加载器**：NeoForge 或 Fabric
- **开发语言**：Java 17+
- **核心依赖**：GeckoLib（3D关键帧动画引擎）+ BlockBench（模型与动画制作工具）


## 二、核心设定（完全基于原版）

### 2.1 主角设定

玩家扮演的是**Alex Mercer**——前 Gentek 公司科学家，在宾夕法尼亚车站被包围后摔碎黑光病毒试管，自身被病毒感染后成为“原型体”。他失去了所有记忆，但获得了超乎常人的能力。作为黑光病毒的化身，Alex 可以**控制自身的生物质（Bio-Mass）**，随意重塑肉体。

### 2.2 核心机制：吞噬（Consume）

吞噬是整个游戏最核心的机制：

> “Every living thing you consume makes you stronger. You take their shapes, and you take their memories.”

**吞噬功能**：
- 抓住任意生物后触发吞噬，吸收其**生物质（Biomass）** 恢复生命值
- 获得被吞噬者的**外貌**，可进行伪装
- 获得被吞噬者的**记忆**，推动剧情发展
- 吞噬特定目标可解锁新能力

**吞噬方式**（原版两种）：
1. **正面吞噬**：直接抓住并吞噬目标
2. **潜行吞噬（Stealth Consume）** ：从背后偷偷接近并吞噬，不触发警报

### 2.3 生物质与能量系统

- Alex 的身体由**生物质（Biomass）** 构成
- 吞噬敌人获取生物质，用于**恢复生命值**和**维持能力**
- 部分能力需要消耗生物质才能使用
- 通过完成主/支线任务和击杀敌人获得**进化点数（Evolution Points / EP）** ，用于在升级菜单中购买新能力和升级


## 三、能力系统（完全基于原版）

### 3.1 攻击能力（Offensive Powers）

原版共有 **6 种主要攻击能力**，按游戏进程逐步解锁：

#### ① 利爪（Claws）—— 第一个获得的武器

| 项目 | 内容 |
|------|------|
| **获取方式** | 吸收**格斗者变异体（Hunter）** ——游戏中的猎人怪兽 |
| **外观描述** | 双手变形为四指/三指的骨质尖爪，如剃刀般锋利 |
| **战斗定位** | 反人员（Anti-Personnel）武器，最适合对付步兵 |
| **攻击速度** | 快 |
| **特殊攻击** | **地刺（Groundspike）** ：将手插入地面，在远处目标脚下爆发大量骨刺；升级后可进行**冲刺斩（Dashing Slice）**  |
| **升级效果** | 范围+25%、伤害+25%、扑击范围提升 |
| **动画要求** | 快速爪击动作，低重心战斗姿态；地刺时手臂插入地面，远处爆发骨刺特效 |

> **原版获取剧情**：玩家在任务中遭遇第一个 Hunter，击晕后吞噬获得利爪能力。

#### ② 巨锤（Hammerfists）—— 第二个获得的武器

| 项目 | 内容 |
|------|------|
| **获取方式** | EP 购买解锁 |
| **外观描述** | 将大量生物质转移到前臂，形成巨大的锤状拳头 |
| **战斗定位** | 反载具（Anti-Vehicle）能力，专门对付坦克和装甲车 |
| **攻击速度** | 慢，但伤害最高 |
| **特殊攻击** | **重击连招（Smackdown）** ：缓慢但高伤害的砸击；**肘击坠（Elbow Slam）** ：跳跃后下砸；**锤投（Hammertoss）** ：冲刺中将自己掷出 |
| **升级效果** | 伤害和范围随升级提升 |
| **动画要求** | 双手巨大化，砸击动作沉重有力，地面产生冲击波特效 |

#### ③ 鞭拳（Whipfist）—— 第三个获得的武器

| 项目 | 内容 |
|------|------|
| **获取方式** | EP 购买解锁 |
| **外观描述** | 右臂延伸出如剃刀般锋利的触手状长鞭 |
| **战斗定位** | 中距离范围攻击，可同时切割大量敌人 |
| **特殊能力** | 可**抓取**远处的敌人和载具；升级后可**远距离抓取（Longshot Grab）** 物体和生物，抢夺坦克或直升机 |
| **动画要求** | 鞭状手臂伸展、挥舞和收缩的流畅动画，抓取时有缠绕特效 |

#### ④ 肌肉增强（Musclemass）—— 第四个获得的武器

| 项目 | 内容 |
|------|------|
| **获取方式** | EP 购买解锁 |
| **外观描述** | 将肌肉物质附着在前臂上，增强力量 |
| **战斗定位** | 强化普通攻击的伤害和威力 |
| **动画要求** | 手臂肌肉膨胀，攻击动作更具力量感 |

#### ⑤ 刀刃（Blade）—— 第五个获得的武器

| 项目 | 内容 |
|------|------|
| **获取方式** | 剧情自动获得——与 Blade 和 Armor 同时解锁 |
| **外观描述** | 右臂变形为巨大的骨刃，能刺穿装甲、将敌人切成两半 |
| **战斗定位** | 所有攻击能力中最强大的，适合切开最坚硬的装甲和感染巢穴 |
| **特殊攻击** | **空中斩（Air Slice）** ；**冲刺连斩（Sprint Frenzy）** ；**刀刃旋风（Blade Tornado）**  |
| **升级效果** | 范围+15%、伤害+25%、旋风斩增加旋转次数 |
| **动画要求** | 右臂化为巨大骨刃，斩击动作大开大合，空中斩有特殊下落动画 |

> **原版获取剧情**：在 Dr. Bradley Ragland 帮助 Alex 移除背部的寄生体后，Alex 恢复能力并自动获得 Blade 和 Armor。

#### ⑥ 热视觉 / 感染视觉（Sensory Powers）—— 感知能力

| 项目 | 内容 |
|------|------|
| **获取方式** | EP 购买解锁 |
| **热感应视觉（Thermal Vision）** | 在烟雾中看清周围，可透视障碍物 |
| **感染探测视觉（Infected Vision）** | 清晰看到被病毒感染的一切 |
| **动画要求** | 屏幕色调切换特效（热感为红橙色，感染为紫色/绿色高亮） |

### 3.2 防御能力（Defensive Powers）

原版有两种防御能力：

#### ① 护盾（Shield）

| 项目 | 内容 |
|------|------|
| **获取方式** | EP 购买解锁（早期即可购买） |
| **外观描述** | 生物质聚集在左前臂，形成骨质盾牌 |
| **功能** | 自动挡住 frontal 攻击；盾牌有吸收伤害的有限容量 |
| **动画要求** | 左臂化为盾牌，受击时有格挡特效 |

#### ② 铠甲（Armor）

| 项目 | 内容 |
|------|------|
| **获取方式** | 与 Blade 同时剧情解锁 |
| **外观描述** | 生物质覆盖全身，形成不断再生的防弹盔甲 |
| **功能** | 全方位减伤（非护盾的单向格挡）；移动速度和敏捷性降低 |
| **动画要求** | 全身覆盖黑色/红色骨质铠甲，移动动作略显沉重 |

### 3.3 伪装能力（Disguise Power）

| 项目 | 内容 |
|------|------|
| **获取方式** | 剧情解锁 |
| **功能** | 变成任何被吞噬者的外貌；获得被变装者的特殊技能、外表和知识；可混入军事基地 |
| **动画要求** | 身体变形/闪烁特效，外观切换平滑 |

### 3.4 移动与跑酷能力（Movement & Parkour）

原版 Alex 拥有超人般的移动能力：

| 能力 | 描述 |
|------|------|
| **超级速度** | 奔跑速度超越车辆 |
| **超级跳跃** | 可跃过建筑物和障碍物 |
| **墙壁奔跑（Wall Running）** | 在墙壁上垂直奔跑 |
| **墙壁攀爬（Wall Crawling）** | 将生物质集中在手掌和脚掌进行攀爬 |
| **滑翔（Glide）** | 高空下落时减缓下落速度 |
| **空中冲刺（Air Dash）** | 在空中向前突进 |
| **空中升级（Air Upgrades）** | 空中冲刺、滑翔等均需 EP 购买升级 |

**动画要求**：
- 奔跑：身体前倾，手臂摆动快速
- 跳跃：蓄力下蹲→弹射
- 墙壁奔跑：身体与墙面平行，四肢交替
- 滑翔：双臂张开如翼
- 空中冲刺：身体前冲带残影特效


## 四、敌人系统（完全基于原版）

### 4.1 三大势力

原版游戏中存在**三大敌对势力**：

1. **病毒变异体（Infected）** —— 被黑光病毒感染的生物
2. **军方（Military）** —— 美国军队，试图消灭所有感染者
3. **Blackwatch** —— 专门处理生化事件的秘密军事组织

### 4.2 主要敌人类型

#### ① 猎人（Hunter）

| 项目 | 内容 |
|------|------|
| **描述** | 大型四足感染生物，由 Elizabeth Greene 创造 |
| **特征** | 体型壮硕、行动快速、力大无穷；可爬墙、投掷物体、跳跃极高；通常集体行动 |
| **威胁等级** | 中等到高等 |
| **吞噬奖励** | **解锁利爪（Claws）**  |

#### ② 猎人首领（Leader Hunter）

| 项目 | 内容 |
|------|------|
| **描述** | 猎人中的首领级个体 |
| **威胁等级** | 高等 |

#### ③ 超级士兵（Super Soldier）

| 项目 | 内容 |
|------|------|
| **描述** | 军方利用病毒技术制作的超级士兵 |
| **特征** | 穿着重型装甲，拥有超人体能和战斗力 |
| **威胁等级** | 中等到高等 |

#### ④ 九头蛇（Hydra）

| 项目 | 内容 |
|------|------|
| **描述** | 大型蛇形感染生物 |
| **特征** | 从地面钻出攻击 |

#### ⑤ 母体（Mother / Elizabeth Greene）

| 项目 | 内容 |
|------|------|
| **描述** | 黑光病毒的原始宿主，代号“母体” |
| **特征** | 拥有与 Alex 相似的能力；是 Blacklight 病毒母株的宿主 |

#### ⑥ 士官长（The Specialist）

| 项目 | 内容 |
|------|------|
| **描述** | Blackwatch 的精英特工 |
| **特征** | 最高级别的军方威胁 |

#### ⑦  supreme Hunter（至高猎人）

| 项目 | 内容 |
|------|------|
| **描述** | 从 Greene 的生物质中诞生的终极 Hunter |
| **特征** | 由 Alex 自身的生物质进化而来 |

### 4.3 军方单位

- **普通士兵**：携带步枪、火箭筒等武器
- **APC**：装甲运兵车
- **坦克**：重型装甲车辆
- **直升机**：空中单位


## 五、剧情与记忆系统（Web of Intrigue）

### 5.1 核心剧情设定

- Alex Mercer 是前 Gentek 科学家，参与了**黑光计划（Blacklight Project）**
- 他发现参与计划的同事被有计划地谋杀后，携带病毒样本企图逃离
- 在宾夕法尼亚车站被包围，临死前摔碎试管，病毒扩散
- Alex 作为“原型体”醒来，**失去所有记忆**，需要吞噬他人来拼凑过去

### 5.2 记忆系统（Web of Intrigue）

| 项目 | 内容 |
|------|------|
| **核心机制** | 吞噬特定目标（尤其是剧情关键人物）可获得其记忆 |
| **功能** | 拼凑 Alex 的过去；揭示黑光病毒和黑光计划背后的阴谋 |
| **奖励** | 关键记忆吞噬可解锁新能力或推动剧情 |
| **视觉呈现** | 吞噬时屏幕闪烁记忆碎片画面 |


## 六、UI/交互需求（基于原版）

### 6.1 能力切换界面

原版使用**屏幕拨号盘（On-Screen Dial）** 切换能力：

| 类别 | 内容 |
|------|------|
| **攻击能力** | 利爪、巨锤、鞭拳、肌肉增强、刀刃 |
| **防御能力** | 护盾、铠甲 |
| **感知能力** | 热视觉、感染视觉 |
| **伪装** | 切换伪装形态 |

### 6.2 HUD 显示

- **生命值**：显示当前生命值
- **生物质/能量条**：显示可用生物质
- **当前能力指示**：显示当前装备的武器形态
- **EP 点数**：显示当前拥有的进化点数

### 6.3 升级菜单（Upgrades Menu）

- 通过 ESC 菜单进入
- 使用 EP 点数购买新能力和升级
- 分类：**能力技能（Powers）、移动技能（Movement）、生存技能（Survivability）** 等


## 七、视觉与动画需求

### 7.1 角色模型

- **基础模型**：Alex Mercer 标志性外观——黑色皮夹克、兜帽、蓝色牛仔裤
- **变形模型**：各武器形态的独立 3D 模型
  - 利爪：双手化为骨质尖爪
  - 巨锤：前臂巨大化，形成锤状
  - 鞭拳：右臂化为触手状长鞭
  - 刀刃：右臂化为巨大骨刃
  - 肌肉增强：前臂肌肉膨胀
  - 护盾：左臂化为骨质盾牌
  - 铠甲：全身覆盖骨质装甲

### 7.2 动画清单

| 类别 | 动画名称 | 描述 |
|------|---------|------|
| **基础** | idle | 待机姿态 |
| | walk / run / sprint | 行走/奔跑/冲刺 |
| | jump / fall | 跳跃/下落 |
| | glide | 滑翔 |
| **战斗** | claw_attack | 利爪连击 |
| | claw_groundspike | 地刺攻击 |
| | hammer_attack | 巨锤砸击 |
| | hammer_elbow_slam | 肘击坠 |
| | whip_attack | 鞭拳抽击 |
| | whip_grab | 鞭拳抓取 |
| | blade_attack | 刀刃斩击 |
| | blade_air_slice | 空中斩 |
| **特殊** | consume | 吞噬动画（触须包裹目标） |
| | stealth_consume | 潜行吞噬 |
| | transform | 形态切换变形 |
| | disguise | 伪装变形 |
| | wall_run | 墙壁奔跑 |
| | air_dash | 空中冲刺 |

### 7.3 特效要求

- **吞噬特效**：红色/黑色触须从 Alex 身体伸出包裹目标
- **地刺特效**：地面爆发出骨刺
- **变形特效**：身体变形时伴随生物质流动和粒子效果
- **攻击特效**：各武器独特的命中特效（血液飞溅、骨刺碎片等）
- **视觉切换**：热视觉（红橙色调）/ 感染视觉（紫色/绿色高亮）


## 八、开发流程建议

### 第一阶段：基础框架（1-2周）
- 搭建开发环境（IDE + Gradle + NeoForge/Fabric）
- 引入 GeckoLib 依赖并完成初始化
- 创建 Alex Mercer 玩家模型和基础动画（idle、walk、run）

### 第二阶段：核心机制（2-3周）
- 实现**吞噬系统**（Consume）—— 抓住目标、吞噬动画、恢复生命
- 实现**伪装系统**（Disguise）—— 变身为被吞噬者的外观
- 实现**记忆系统**（Web of Intrigue）—— 吞噬特定目标获得记忆

### 第三阶段：攻击能力（3-4周）
- 按原版顺序实现所有武器形态：
  1. 利爪（Claws）—— 吞噬 Hunter 解锁
  2. 巨锤（Hammerfists）—— EP 购买
  3. 鞭拳（Whipfist）—— EP 购买
  4. 肌肉增强（Musclemass）—— EP 购买
  5. 刀刃（Blade）—— 剧情解锁
- 每个武器独立模型、动画、攻击逻辑

### 第四阶段：防御与感知（1-2周）
- 护盾（Shield）—— EP 购买
- 铠甲（Armor）—— 与 Blade 同时剧情解锁
- 热视觉（Thermal Vision）—— EP 购买
- 感染视觉（Infected Vision）—— EP 购买

### 第五阶段：移动能力（2-3周）
- 超级跳跃、超级速度
- 墙壁奔跑 / 墙壁攀爬
- 滑翔（Glide）
- 空中冲刺（Air Dash）

### 第六阶段：敌人系统（2-3周）
- 实现所有原版敌人类型（Hunter、Leader Hunter、Super Soldier、Hydra 等）
- 实现军方单位（士兵、APC、坦克、直升机）
- 实现 Boss 战（Supreme Hunter、Elizabeth Greene 等）

### 第七阶段：UI与优化（1-2周）
- 能力切换拨号盘
- 升级菜单（EP 购买系统）
- HUD（生命值、生物质、EP）
- 性能优化与 Bug 修复
